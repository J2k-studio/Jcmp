# Guides
* **Learning from zero:** [LEARN.md](LEARN.md) ([English](LEARN_EN.md)): one path from "what is a computer" to the deep subjects, with a 7-day start.

Start with [TUTORIAL.md](TUTORIAL.md) (the lessons, in order). The guides below go deeper into one
subject each. Every program in them was compiled and run; the text says where something was not run.

| Guide | What it covers |

| [PERFORMANCE.md](PERFORMANCE.md) | speed (written by another worker; may not exist yet) |

| [INTEROP.md](INTEROP.md) | a J2K shared library called from C, Python and Java |
| [BUILD.md](BUILD.md) | `makej`, libraries, `jc`, versions, the compile cache |
| [SYSTEMS.md](SYSTEMS.md) | pointers, memory, `Sys::`, threads, atomics, ownership |
| [SIMD.md](SIMD.md) | vector types, the vectoriser, fused multiply-add, the machine code |
| [GPU.md](GPU.md) | `<gpu>`, `<canvas2d>`, OpenGL ES (`<opengl3>`), Vulkan (compute) |
| [NPU.md](NPU.md) | the NPU of the phone through NNAPI (`<npu>`) |
| [APP_PACKAGING.md](APP_PACKAGING.md) | `makej apk`, `apkj`, the manifest, signing, `pack` and `dist` |
