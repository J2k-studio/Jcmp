# Learn how a computer works, from the bit up to your program

This is a path for a person who writes code and wants to understand what happens under it. Each chapter is short, has a program you can run, and ends with questions. You need a phone or a computer with `jcmp` (`jc install jcmp`).

| # | chapter | the question it answers |
|---|---|---|
| 1 | [The computer and the bit](01-computer-and-bits.md) | what is a bit, a byte, a number, a letter, a picture inside the machine |
| 2 | [The CPU](02-cpu.md) | what does the processor do, what is a register, a cache, a core |
| 3 | [The GPU](03-gpu.md) | why does the graphics chip do some jobs 20 times faster |
| 4 | [Binary and assembly](04-binary-and-assembly.md) | what is machine code, and what does `jcmp` write for your line |
| 5 | [Layers: the stack of a program](05-code-structure.md) | from the source file to the electricity; and how to lay out your own project |
| 6 | [Putting your project on GitHub](06-github.md) | how to keep, share and release what you wrote |

The tutorial `docs/TUTORIAL.md` (lessons 76 to 82) goes further into numbers, floating point, gates, a tiny CPU and ARM64 encoding. Read the chapters in order the first time; later, use them as a reference.

How to read: run every program, change one thing, predict the output before you run it. If your prediction was wrong, that is where you learn.
