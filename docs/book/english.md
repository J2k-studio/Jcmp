# English

## อ่านข้อความของคอมไพเลอร์
**คืออะไร.** ข้อความของคอมไพเลอร์มีตำแหน่ง และมีชนิด ตำแหน่งคือชื่อไฟล์ บรรทัด และคอลัมน์ ชนิดคือ error หรือ warning คำที่ตามหลังบอกว่าอะไรผิด ข้อความเขียนเป็นภาษาอังกฤษ จึงคำอังกฤษสั้นๆ เป็นส่วนหนึ่งของบทนี้
**ทำไมต้องรู้.** เมื่อโปรแกรมสร้างไม่ได้ ข้อความคือเบาะแสเดียวที่คุณมี ถ้ารู้คำสั้นๆ คุณจะรู้ว่าต้องดูตรงไหนและต้องแก้อะไร โดยไม่ต้องเดา
**ทำอย่างไร.**

อ่านชื่อไฟล์และหมายเลขบรรทัดก่อน แล้วไปที่บรรทัดนั้น อ่านคำที่ตามตำแหน่ง: error หมายถึงโปรแกรมจะไม่ถูกสร้าง warning หมายถึงโปรแกรมถูกสร้างแต่อาจมีอะไรผิด อ่านที่เหลือทีละคำ แล้วค่อยแก้โค้ด
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    jout << "Read the line number first\n";
}
```

```
Read the line number first
```

> **ระวัง:** ผู้เรียนหลายคนอ่านแค่คำแรกแล้วหยุด ให้อ่านตำแหน่งด้วย หมายเลขบรรทัดบอกว่าต้องดูตรงไหน
**แบบฝึกหัด**
- ข้อความขึ้นว่า main.jk:5:3: error คำว่า error บอกอะไร
  - a) ไฟล์ผิด  b) โปรแกรมไม่ถูกสร้าง  c) โปรแกรมเร็ว  — เฉลย: b. error ทำให้การสร้างหยุด warning ไม่หยุด จึงเป็นคำที่ร้ายแรงกว่า
- ส่วนไหนของข้อความบอกบรรทัดที่มีปัญหา
  - a) คำว่า error  b) ตัวเลขหลังชื่อไฟล์  c) คำสุดท้าย  — เฉลย: b. หลังชื่อไฟล์คือหมายเลขบรรทัด แล้วตามด้วยคอลัมน์ ดังนั้น 5 ใน main.jk:5:3 คือบรรทัด
- warning และ error ทำให้คอมไพเลอร์หยุดไม่สร้างโปรแกรมทั้งคู่ — เฉลย: f. มีแค่ error ที่หยุดการสร้าง warning เป็นหมายเหตุว่าอาจมีอะไรผิด
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << "error" << "\n";
}
```
  ผลลัพธ์ที่ได้: `error`. ข้อความในเครื่องหมายคำพูดจะถูกพิมพ์ตามที่เขียน เครื่องหมายคำพูดไม่ถูกพิมพ์
- ในข้อความ main.jk:5:3 เลข 3 คือ ___ — เฉลย: **column**. คอลัมน์คือตำแหน่งในบรรทัด ตัวอักษรตัวแรกของบรรทัดคือคอลัมน์ 1
- อ่านข้อความของคอมไพเลอร์: หาชื่อไฟล์และบรรทัด → อ่านคำว่า error หรือ warning → ไปที่บรรทัดนั้น → อ่านที่เหลือแล้วแก้โค้ด. ต้องรู้ว่าปัญหาอยู่ตรงไหนและเป็นชนิดใด ก่อนจะแก้อะไร
**โจทย์**
- **คำเตือน** — เขียนโปรแกรมที่พิมพ์คำว่า warning และขึ้นบรรทัดใหม่. ผลลัพธ์ที่ได้: `warning`. คำใบ้: ใช้ jout กับคำในเครื่องหมายคำพูด และจบด้วย \n

## กริยาของโค้ด
**คืออะไร.** บรรทัดส่วนใหญ่ของโค้ดมีกริยาอยู่ print ส่งค่าออกไป store เก็บค่าไว้ใต้ชื่อ compare เทียบสองค่าแล้วได้คำตอบว่าใช่หรือไม่ repeat ทำซ้ำบรรทัดเดิมหลายรอบ เรียนห้าคำนี้แล้วคุณอ่านโปรแกรมสั้นๆ ได้เกือบทั้งหมด
**ทำไมต้องรู้.** กริยาบอกว่าโปรแกรมทำอะไร เมื่ออ่านโปรแกรมเป็นภาษาอังกฤษ ให้หากริยาก่อน แล้วค่อยหาสิ่งที่กริยาทำกับ
**ทำอย่างไร.**

อ่านบรรทัดจากซ้ายไปขวา หากริยาก่อน: jout พิมพ์ int เก็บตัวเลข if เทียบ for ทำซ้ำ แล้วหาค่าที่กริยานั้นทำด้วย ตัวอย่างเก็บเลข 3 พิมพ์มัน แล้วทำซ้ำสามรอบ
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int count = 3;
    jout << count << "\n";
    for i in 0..count { jout << "repeat " << i << "\n"; }
}
```

```
3
repeat 0
repeat 1
repeat 2
```

> **ระวัง:** ช่วง 0..count หยุดก่อนค่า count มันทำงาน 0, 1 และ 2 ไม่ถึง 3 เป็นกฎเดียวกับ 1..1001 ในบทเครื่อง
**แบบฝึกหัด**
- ในบรรทัด int count = 3; คำไหนเป็นชื่อที่ใช้เก็บค่า
  - a) int  b) count  c) 3  — เฉลย: b. int บอกชนิดของค่า 3 คือค่าที่เก็บ และ count คือชื่อที่ใช้เรียกค่านั้น
- กริยาใดตรวจว่าสองค่าเท่ากันหรือไม่
  - a) print  b) compare  c) repeat  — เฉลย: b. compare คือการเทียบ ให้คำตอบเป็นใช่หรือไม่ใช่
- บรรทัด for i in 0..3 ทำงานบล็อก 3 รอบ โดย i เป็น 0, 1 และ 2 — เฉลย: t. ช่วง 0..3 เริ่มที่ 0 และหยุดก่อน 3
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
for i in 0..2 { jout << "go " << i << "\n"; }
}
```
  ผลลัพธ์ที่ได้: `go 0 / go 1`. ลูปทำงานเมื่อ i เป็น 0 และ 1 แล้วหยุดก่อน 2
- กริยาที่ส่งค่าออกไปที่หน้าจอคือ ___ — เฉลย: **print**. ใน J2K ใช้คำว่า jout กับ << เพื่อพิมพ์ค่า
- เก็บเลขแล้วพิมพ์: ประกาศ int n = 5 → เขียน jout << n << "\n" → สั่งสร้างและรันไฟล์. ต้องมีชื่อก่อนจึงพิมพ์ได้ จึงต้องเก็บค่าก่อน
**โจทย์**
- **นับถึงสอง** — เขียนโปรแกรมที่ทำซ้ำ for i in 0..2 และพิมพ์คำว่า tick ตามด้วยค่า i ทุกรอบ. ผลลัพธ์ที่ได้: `tick 0 / tick 1`. คำใบ้: ใช้ for loop หนึ่งลูก และ jout ที่มีช่องว่างระหว่างคำกับ i

## คำนาม: name, value, type และ list
**คืออะไร.** คำนามคือชื่อของสิ่งต่างๆ ในโค้ด name คือคำที่คุณเลือกเรียกค่า เช่น count หรือ total value คือค่าที่เก็บไว้ใต้ชื่อ เช่น 3 type บอกชนิดของค่า เช่น int คือจำนวนเต็ม list คือหลายค่าเรียงกันเป็นแถว ซึ่งบทเรียนเรียกว่า array
**ทำไมต้องรู้.** คุณเขียน name, value, type และ list ในทุกโปรแกรม ถ้าสับสนกัน คอมไพเลอร์จะบอกข้อความเรื่องชนิด และคุณต้องรู้คำนั้นเพื่ออ่านข้อความ
**ทำอย่างไร.**

อ่านการประกาศจากซ้ายไปขวา ชนิดมาก่อน แล้วชื่อ แล้วค่าหลังเครื่องหมายเท่ากับ ตัวอย่างมีหนึ่งชื่อชนิด int ค่า 4 และหนึ่งลิสต์ของตัวเลขสามตัว
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int width = 4;
    int nums[3] = {10, 20, 30};
    jout << "width " << width << "\n";
    jout << "first " << nums[0] << "\n";
}
```

```
width 4
first 10
```

> **ระวัง:** ลิสต์นับเริ่มที่ 0 ค่าแรกของ nums คือ nums[0] ไม่ใช่ nums[1]
**แบบฝึกหัด**
- ใน int width = 4; คำไหนเป็นชนิด
  - a) width  b) int  c) 4  — เฉลย: b. ชนิดคือประเภทของค่า int คือจำนวนเต็ม ส่วนชื่อคือคำที่ตามหลังชนิด
- ในลิสต์ nums[3] ค่าแรกอยู่ที่ไหน
  - a) nums[1]  b) nums[0]  c) nums[3]  — เฉลย: b. ลิสต์เริ่มนับที่ 0 ค่าแรกจึงเป็น nums[0]
- ชื่อกับค่าเป็นสิ่งเดียวกัน — เฉลย: f. ชื่อคือป้ายของกล่อง ส่วนค่าคือสิ่งที่อยู่ในกล่อง
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int nums[2] = {7, 8};
jout << nums[1] << "\n";
}
```
  ผลลัพธ์ที่ได้: `8`. ดัชนี 1 คือค่าที่สองในลิสต์ ซึ่งคือ 8
- ลิสต์ที่มีหลายค่าในแถวเดียวเรียกว่า ___ — เฉลย: **array**. array เก็บค่าชนิดเดียวกันไว้ติดกัน
- สร้างชื่อแล้วแสดงค่า: เลือกชื่อ → กำหนดชนิด → ใส่ค่า → พิมพ์ค่า. ต้องเลือกชื่อและชนิดก่อนจึงใส่ค่าได้
**โจทย์**
- **สองชื่อ** — เขียนโปรแกรมที่มี int a = 2 และ int b = 5 แล้วพิมพ์คำว่า sum ตามด้วยค่า a + b. ผลลัพธ์ที่ได้: `sum 7`. คำใบ้: ใช้ jout กับข้อความ sum ช่องว่าง และ a + b

## คำเล็กๆ: if, else, while และ for
**คืออะไร.** คำเล็กๆ คือเครื่องหมายของการควบคุม if หมายถึงทำบล็อกเฉพาะเมื่อเงื่อนไขเป็นจริง else หมายถึงกรณีอื่นทั้งหมด while ทำซ้ำตราบที่เงื่อนไขยังเป็นจริง for ทำซ้ำตามช่วงของตัวเลข แต่ละคำมีคำถามอยู่ข้างหน้าที่คุณอ่านเป็นภาษาอังกฤษได้
**ทำไมต้องรู้.** โปรแกรมต้องเลือกและทำซ้ำงาน ถ้าอ่าน if กับ else เป็นภาษาอังกฤษ คุณจะเห็นการเลือกก่อนรันโปรแกรม
**ทำอย่างไร.**

อ่านเงื่อนไขเป็นคำถาม เช่น if count < 3 หมายถึง count น้อยกว่า 3 หรือไม่ ถ้าใช่ บล็อกจะทำงาน ถ้าไม่ใช่ บล็อก else จะทำงาน
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int count = 2;
    if count < 3 { jout << "small\n"; } else { jout << "big\n"; }
}
```

```
small
```

> **ระวัง:** เงื่อนไขต้องเป็นคำถามที่ตอบใช่หรือไม่ได้ เขียน if count < 3 ไม่ใช่ if count เพราะตัวเลขไม่ใช่คำตอบใช่หรือไม่
**แบบฝึกหัด**
- ใน if x > 5 คำว่า if หมายความว่าอะไร
  - a) ทำเสมอ  b) ทำเฉพาะเมื่อเงื่อนไขเป็นจริง  c) ทำตลอดไป  — เฉลย: b. if ทำบล็อกเฉพาะเมื่อเงื่อนไขเป็นจริง ไม่เช่นนั้นข้ามไป
- คำเล็กคำใดทำบล็อกซ้ำตราบที่เงื่อนไขเป็นจริง
  - a) for  b) while  c) else  — เฉลย: b. while ตรวจเงื่อนไขก่อนทุกรอบ และหยุดเมื่อเป็นเท็จ
- else ทำบล็อกเมื่อเงื่อนไข if เป็นจริง — เฉลย: f. else ทำงานเมื่อเงื่อนไข if เป็นเท็จ ไม่ใช่เมื่อจริง
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int n = 1;
if n == 1 { jout << "one\n"; } else { jout << "other\n"; }
}
```
  ผลลัพธ์ที่ได้: `one`. เงื่อนไข n == 1 เป็นจริง บล็อกแรกจึงทำงาน
- คำที่ทำบล็อกซ้ำให้แต่ละเลขในช่วงคือ ___ — เฉลย: **for**. for i in 0..3 ทำงานกับเลข 0, 1 และ 2
- อ่านการเลือกเป็นภาษาอังกฤษ: อ่านคำว่า if → อ่านเงื่อนไขเป็นคำถาม → อ่านบล็อกของคำตอบใช่ → อ่านบล็อก else ของคำตอบไม่ใช่. คำถามมาก่อน แล้วจึงคำตอบสองแบบ
**โจทย์**
- **เลือกคำ** — เขียนโปรแกรมที่มี int x = 9 ถ้า x มากกว่า 5 พิมพ์ big ไม่เช่นนั้นพิมพ์ small. ผลลัพธ์ที่ได้: `big`. คำใบ้: ใช้ if x > 5 กับบล็อกหนึ่ง และ else กับอีกบล็อกหนึ่ง

## เอกพจน์และพหูพจน์
**คืออะไร.** เอกพจน์หมายถึงหนึ่งสิ่ง พหูพจน์หมายถึงหลายสิ่ง ในโค้ด ค่าเดียวคือตัวเลขหนึ่งตัว ส่วนลิสต์คือหลายค่า ชื่อของลิสต์มักใช้พหูพจน์ เช่น numbers หรือ names เพราะเก็บหลายค่า
**ทำไมต้องรู้.** ชื่อที่ดีบอกว่ามีกี่สิ่งอยู่ข้างใน ถ้าลิสต์ชื่อ number แทนที่จะเป็น numbers ผู้อ่านจะคิดว่ามีค่าเดียว โค้ดจึงอ่านยาก
**ทำอย่างไร.**

เมื่อตั้งชื่อค่าเดียว ใช้เอกพจน์ เช่น count หรือ total เมื่อตั้งชื่อลิสต์ ใช้พหูพจน์ เช่น scores หรือ names แล้วอ่านชื่อในประโยค เช่น the scores are ten and twenty
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int score = 10;
    int scores[2] = {10, 20};
    jout << "score " << score << "\n";
    jout << "scores " << scores[1] << "\n";
}
```

```
score 10
scores 20
```

> **ระวัง:** อย่าตั้งชื่อพหูพจน์ให้ค่าเดียว ชื่ออย่าง scores สำหรับตัวเลขหนึ่งตัวทำให้ผู้อ่านรายถัดไปต้องแก้
**แบบฝึกหัด**
- ชื่อใดเหมาะสำหรับตัวเลขหนึ่งตัวที่นับจำนวนนักเรียน
  - a) students  b) count  c) students_list  — เฉลย: b. count เป็นเอกพจน์และบอกว่าค่าคือตัวเลขหนึ่งตัว
- ชื่อใดเหมาะสำหรับลิสต์ชื่อของนักเรียน
  - a) name  b) names  c) nameName  — เฉลย: b. names เป็นพหูพจน์ บอกว่าลิสต์เก็บหลายค่า
- พหูพจน์เหมาะกับลิสต์ที่เก็บหลายค่า — เฉลย: t. ชื่อพหูพจน์บอกผู้อ่านว่าตัวแปรเก็บมากกว่าหนึ่งค่า
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int scores[2] = {3, 4};
jout << scores[0] + scores[1] << "\n";
}
```
  ผลลัพธ์ที่ได้: `7`. บวกสองค่าเข้าด้วยกัน 3 บวก 4 เท่ากับ 7
- ชื่อที่เก็บหลายค่าควรอยู่ในรูป ___ — เฉลย: **plural**. ใช้พหูพจน์กับลิสต์ เช่น names หรือ scores
- ตั้งชื่อลิสต์คะแนน: เลือกคำพหูพจน์ marks → เขียนชนิดและขนาด → ใส่ค่า → อ่านค่าหนึ่งตัวด้วยดัชนี. การเลือกพหูพจน์เป็นการตัดสินใจแรก เพื่อให้ผู้อ่านรู้ว่ามีหลายค่า
**โจทย์**
- **คะแนนรวม** — เขียนโปรแกรมที่มี int scores[3] = {1, 2, 3} แล้วพิมพ์คำว่า total ตามด้วยผลรวมของสามค่า. ผลลัพธ์ที่ได้: `total 6`. คำใบ้: ใช้ scores[0] + scores[1] + scores[2] ใน jout

## อ่านประโยคเป็นโค้ด
**คืออะไร.** โค้ดหลายบรรทัดอ่านเป็นประโยคภาษาอังกฤษได้ เช่นประโยค If the value is less than ten, print it หมายความว่า ตรวจว่า value น้อยกว่า 10 หรือไม่ ถ้าใช่ ให้พิมพ์ value การเปลี่ยนประโยคเป็นโค้ดเป็นทักษะหนึ่ง
**ทำไมต้องรู้.** โปรแกรมส่วนใหญ่เริ่มจากประโยคในหัว ถ้าเขียนประโยคก่อนแล้วแปลเป็นโค้ด โปรแกรมจะถูกต้องได้ง่ายกว่า
**ทำอย่างไร.**

หากริยา วัตถุ และเงื่อนไขในประโยค แล้วเขียนเงื่อนไขหลัง if และกริยาตามหลัง ตัวอย่างแปลประโยค If the value is less than ten, print it เป็นโค้ด
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int value = 7;
    if value < 10 { jout << value << "\n"; }
}
```

```
7
```

> **ระวัง:** ประโยคที่มีคำว่า and มักต้องมีสองเงื่อนไข เขียนแต่ละอันเป็น if ของตัวเอง หรือต่อด้วย && ในหนึ่ง if
**แบบฝึกหัด**
- โค้ดใดคือประโยค If the value is zero, print the word none
  - a) if value > 0 { jout << "none\n"; }  b) if value == 0 { jout << "none\n"; }  c) print none  — เฉลย: b. value is zero คือ value == 0 เครื่องหมาย == หมายถึงเท่ากับ
- คำว่า it ใน print it หมายถึงอะไร
  - a) คำว่า print  b) ค่าที่ถูกตรวจ  c) โปรแกรม  — เฉลย: b. it ชี้ไปที่ค่าที่เพิ่งถูกเอ่ยถึงในประโยค
- เครื่องหมาย = ใช้ถามคำถามเกี่ยวกับสองค่า — เฉลย: f. = เดียวให้ค่ากับชื่อ ถ้าต้องการถามคำถามให้ใช้ ==
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int v = 4;
if v > 2 { jout << "more\n"; }
}
```
  ผลลัพธ์ที่ได้: `more`. ประโยค v is greater than 2 เป็นจริง บล็อกจึงพิมพ์ more
- เครื่องหมายเท่ากับในเงื่อนไขคือ == ซึ่งเขียนเป็นเครื่องหมายเท่ากับ ___ ตัว — เฉลย: **two**. สองตัวทำให้เป็นคำถาม ตัวเดียวให้ค่า
- แปลประโยคเป็นโค้ด: หากริยา print → หาเงื่อนไข if value is less than ten → เขียน if value < 10 → เขียนบล็อกด้วย jout. หาทั้งกริยาและเงื่อนไขก่อนเขียนโค้ด
**โจทย์**
- **ประโยคเป็นโค้ด** — เขียนโปรแกรมที่มี int age = 12 ถ้า age น้อยกว่า 18 พิมพ์คำว่า minor. ผลลัพธ์ที่ได้: `minor`. คำใบ้: ใช้ if age < 18 กับ jout ในบล็อก

## คอมเมนต์เป็นภาษาอังกฤษ
**คืออะไร.** คอมเมนต์คือหมายเหตุสำหรับผู้อ่าน คอมไพเลอร์ข้ามมัน เครื่องหมายทับสองตัว // ทำให้ข้อความหลังมันถึงท้ายบรรทัดเป็นคอมเมนต์ ส่วน /* ... */ ทำให้ครอบหลายบรรทัดได้
**ทำไมต้องรู้.** โค้ดบอกว่าเกิดอะไรขึ้น คอมเมนต์บอกว่าทำไม เขียนคอมเมนต์เป็นภาษาอังกฤษง่ายๆ เพื่อให้ผู้เรียนคนถัดไปอ่านได้
**ทำอย่างไร.**

เขียนคอมเมนต์สั้นๆ เหนือบรรทัดที่ยาก และบอกเหตุผล ไม่ใช่สิ่งที่โค้ดทำอยู่แล้ว ตัวอย่างมีคอมเมนต์หนึ่งบรรทัดที่อธิบายความหมายของตัวเลข
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    // 60 seconds make one minute
    int seconds = 60;
    jout << seconds << "\n";
}
```

```
60
```

> **ระวัง:** คอมเมนต์ที่ทวนโค้ด เช่น เพิ่มหนึ่งให้ x เหนือ x = x + 1 ไม่ช่วยอะไร ให้อธิบายเหตุผลแทน
**แบบฝึกหัด**
- บรรทัดใดเป็นคอมเมนต์ที่ดี
  - a) // x = x + 1  b) // add the tax, because the price is before tax  c) // int x  — เฉลย: b. คอมเมนต์ที่ดีอธิบายว่าทำไม ตัวเลือกแรกเพียงทวนโค้ด
- จะเขียนคอมเมนต์ที่ครอบสามบรรทัดอย่างไร
  - a) ใส่ // ทุกบรรทัด  b) ใส่ /* และ */ ครอบบรรทัด  c) ใส่เครื่องหมายแฮช  — เฉลย: b. /* เริ่มคอมเมนต์ และ */ ปิดคอมเมนต์ จึงครอบหลายบรรทัดได้
- คอมไพเลอร์อ่านข้อความในคอมเมนต์แล้วรันมัน — เฉลย: f. คอมไพเลอร์ข้ามคอมเมนต์ มีไว้เพื่อผู้อ่านเท่านั้น
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
// this line is not printed
jout << "shown\n";
}
```
  ผลลัพธ์ที่ได้: `shown`. บรรทัดที่ขึ้นต้นด้วย // เป็นคอมเมนต์และถูกข้าม
- สองตัวอักษรที่เริ่มคอมเมนต์ถึงท้ายบรรทัดคือ ___ — เฉลย: **//**. เครื่องหมายทับสองตัวทำให้เป็นคอมเมนต์ถึงท้ายบรรทัด
- เขียนคอมเมนต์ที่มีประโยชน์: อ่านบรรทัดที่ต้องการหมายเหตุ → ตัดสินใจว่าทำไมจึงมี → เขียนเหตุผลเป็นภาษาอังกฤษง่ายๆ → วางคอมเมนต์เหนือบรรทัด. เหตุผลคือส่วนที่โค้ดไม่ได้บอก
**โจทย์**
- **พิมพ์พร้อมคอมเมนต์** — เขียนโปรแกรมที่มีคอมเมนต์หนึ่งอันมีคำว่า hello และพิมพ์คำว่า done. ผลลัพธ์ที่ได้: `done`. คำใบ้: ใช้ // สำหรับคอมเมนต์ และ jout สำหรับ done

## ชื่อที่ดี
**คืออะไร.** ชื่อที่ดีควรบอกว่าค่านั้นใช้ทำอะไร count, total และ first_name เป็นชื่อที่ดี ส่วน x, tmp และ data เป็นชื่อสั้นที่ไม่บอกอะไรผู้อ่าน ชื่อภาษาอังกฤษอ่านง่ายเมื่อใช้คำธรรมดา และเครื่องหมายขีดล่าง _ เชื่อมสองคำ
**ทำไมต้องรู้.** คุณอ่านชื่อมากกว่าการเขียนชื่อหลายเท่า ชื่อที่ดีช่วยให้ผู้อ่านไม่ต้องย้อนกลับไปดูที่ที่ค่าถูกสร้าง
**ทำอย่างไร.**

เลือกชื่อที่ตอบคำถามว่าสิ่งนี้ใช้ทำอะไร ใช้คำอังกฤษสั้นหนึ่งหรือสองคำ คั่นด้วยขีดล่าง อย่าใช้ชื่อตัวอักษรเดียว ยกเว้นตัวแปรนับของลูป เช่น i
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int first_score = 8;
    int total_score = first_score + 2;
    jout << "total " << total_score << "\n";
}
```

```
total 10
```

> **ระวัง:** ชื่ออย่าฉลาดเกินไป tmp2 ไม่บอกอะไร ให้ใช้ชื่อที่ผู้เรียนอ่านออกเสียงได้
**แบบฝึกหัด**
- ชื่อใดบอกความหมายของค่ามากที่สุด
  - a) x  b) total_score  c) t2  — เฉลย: b. total_score บอกผู้อ่านว่าค่านั้นหมายถึงอะไร ส่วน x และ t2 ไม่บอก
- ชื่อใดเป็นชื่อปกติของตัวแปรนับในลูป
  - a) i  b) total  c) last_value_of_the_loop  — เฉลย: a. i เป็นชื่อปกติของตัวนับลูป เป็นกรณียกเว้นที่ชื่อตัวเดียวดี
- ขีดล่างใน first_name คือช่องว่างที่ใช้ได้ — เฉลย: f. ชื่อห้ามมีช่องว่าง ขีดล่างจึงเชื่อมสองคำให้เป็นชื่อเดียว
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int count = 3;
int total_count = count + 1;
jout << total_count << "\n";
}
```
  ผลลัพธ์ที่ได้: `4`. count เป็น 3 และบวกหนึ่ง total_count จึงเป็น 4
- ชื่อผลรวมของคะแนนอาจเป็น total___ — เฉลย: **score**. total_score บอกว่าค่าใช้ทำอะไร คือผลรวมของคะแนน
- เลือกชื่อที่ดีให้ค่า: บอกว่าค่าใช้ทำอะไร → เขียนเป็นคำอังกฤษธรรมดา → เชื่อมคำด้วยขีดล่าง → ตรวจว่าผู้อ่านเข้าใจหรือไม่. ความหมายมาก่อน ชื่อจึงตามมา
**โจทย์**
- **ชื่อดี** — เขียนโปรแกรมที่มี int apple_count = 4 แล้วพิมพ์คำว่า apples ตามด้วยค่าของ apple_count. ผลลัพธ์ที่ได้: `apples 4`. คำใบ้: ใช้ jout กับข้อความ apples ช่องว่าง และ apple_count

## คำคุณศัพท์: big, small, empty
**คืออะไร.** คำคุณศัพท์ขยายคำนาม ในโค้ดค่าของชื่ออาจเป็น big, small หรือ empty เลขใหญ่คือมากกว่าเลขอื่น เลขเล็กคือน้อยกว่า ลิสต์ว่าง (empty) คือไม่มีค่าอยู่ข้างใน และจำนวนศูนย์คือไม่มีอะไรให้นับ
**ทำไมต้องรู้.** บทเรียนหลายบทเขียนว่า if the list is empty หรือ if the value is bigger ถ้ารู้คำคุณศัพท์ คุณจะอ่านเงื่อนไขได้ทันทีว่าโปรแกรมตรวจอะไร
**ทำอย่างไร.**

เปลี่ยนคำคุณศัพท์เป็นการเปรียบเทียบ big คือมากกว่า small คือน้อยกว่า empty คือจำนวนเป็นศูนย์ ตัวอย่างตรวจจำนวนที่เป็นศูนย์แล้วพิมพ์ข้อความของกรณีว่าง
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int count = 0;
    if count == 0 { jout << "empty\n"; } else { jout << "not empty\n"; }
}
```

```
empty
```

> **ระวัง:** คำว่า empty ไม่ใช่คำสงวน มันเป็นการตรวจธรรมดา เช่น count == 0 จึงควรเขียนการตรวจที่คุณหมายถึง
**แบบฝึกหัด**
- ถ้าลิสต์ว่าง จำนวนของมันคือเท่าไร
  - a) 1  b) 0  c) empty  — เฉลย: b. empty หมายถึงไม่มีค่า จำนวนจึงเป็นศูนย์
- เงื่อนไขใดหมายความว่าค่านั้นน้อย
  - a) value > 100  b) value < 10  c) value == 10  — เฉลย: b. small หมายถึงค่าน้อยกว่าขีดจำกัด ในที่นี้คือ 10
- คำคุณศัพท์ big หมายถึงมากกว่าในการเปรียบเทียบ — เฉลย: t. big คือคำสำหรับเลขที่มากกว่า จึงกลายเป็นเครื่องหมายมากกว่า
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int n = 5;
if n > 3 { jout << "big\n"; }
}
```
  ผลลัพธ์ที่ได้: `big`. ค่า 5 มากกว่า 3 คำว่า big จึงเป็นจริง
- จำนวนศูนย์หมายความว่าลิสต์ ___ — เฉลย: **empty**. ศูนย์ค่าหมายความว่าไม่มีอะไรอยู่ในลิสต์
- ตรวจลิสต์ว่าง: เขียนจำนวน → เทียบกับศูนย์ → พิมพ์ข้อความของกรณีว่าง → พิมพ์อีกข้อความ. ต้องมีจำนวนก่อนจึงเทียบได้
**โจทย์**
- **ตรวจค่าใหญ่** — เขียนโปรแกรมที่มี int n = 50 ถ้า n ใหญ่ คือมากกว่า 10 พิมพ์ big ไม่เช่นนั้นพิมพ์ small. ผลลัพธ์ที่ได้: `big`. คำใบ้: ใช้ if n > 10 กับ jout ในบล็อก

## ตัวเลขในคำพูด: zero, first, last, half
**คืออะไร.** คำเกี่ยวกับตัวเลขบางคำมีความหมายพิเศษในการเขียนโปรแกรม zero คือจำนวนของสิ่งที่ไม่มี first ค่าแรกของลิสต์มีดัชนี 0 ไม่ใช่ 1 last คือค่าสุดท้ายซึ่งมีดัชนีน้อยกว่าขนาดหนึ่ง half ของเลขคือเลขนั้นหารด้วยสอง
**ทำไมต้องรู้.** บั๊กแบบ off-by-one เกิดจากการสับสนคำว่า first, last และ zero เมื่ออ่านคำว่า first ให้นึกถึงดัชนี 0 ในโค้ด
**ทำอย่างไร.**

สำหรับลิสต์ขนาด 4 ดัชนีแรกคือ 0 และดัชนีสุดท้ายคือ 3 ตัวอย่างพิมพ์ทั้งสองค่า
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int nums[4] = {5, 6, 7, 8};
    jout << "first " << nums[0] << "\n";
    jout << "last " << nums[3] << "\n";
}
```

```
first 5
last 8
```

> **ระวัง:** ดัชนีสุดท้ายของลิสต์ขนาด 4 คือ 3 ไม่ใช่ 4 ดัชนี 4 อยู่นอกลิสต์แล้ว
**แบบฝึกหัด**
- ในลิสต์ขนาด 4 ดัชนีใดคือค่าสุดท้าย
  - a) 4  b) 3  c) 0  — เฉลย: b. ดัชนีเริ่มที่ 0 เมื่อมีสี่ค่า ดัชนีสุดท้ายคือ 3
- ดัชนีแรกของลิสต์ทุกลิสต์คือเท่าไร
  - a) 1  b) 0  c) ขนาดของลิสต์  — เฉลย: b. ค่าแรกของ J2K อยู่ที่ดัชนี 0 เสมอ
- ครึ่งหนึ่งของ 9 เป็นจำนวนเต็มคือ 4 — เฉลย: t. การหารจำนวนเต็ม 9 ด้วย 2 เก็บเฉพาะส่วนจำนวนเต็ม ได้ 4
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int a[3] = {2, 4, 6};
jout << a[0] << "\n";
}
```
  ผลลัพธ์ที่ได้: `2`. ค่าแรกของลิสต์อยู่ที่ดัชนี 0 และค่านั้นคือ 2
- ดัชนีของค่าแรกในลิสต์คือ ___ — เฉลย: **0**. ลิสต์นับจากศูนย์ ค่าแรกจึงอยู่ที่ดัชนี 0
- อ่านค่าสุดท้ายของลิสต์: เขียนลิสต์ → หาขนาด → ลบหนึ่งเพื่อได้ดัชนีสุดท้าย → อ่านค่าที่ดัชนีนั้น. ดัชนีสุดท้ายน้อยกว่าขนาดหนึ่ง จึงต้องลบก่อน
**โจทย์**
- **ค่าสุดท้าย** — เขียนโปรแกรมที่มี int a[3] = {7, 8, 9} และพิมพ์คำว่า last ตามด้วยค่าสุดท้าย. ผลลัพธ์ที่ได้: `last 9`. คำใบ้: ดัชนีสุดท้ายของสามค่าคือ 2

## คำถาม: what, which, why, how
**คืออะไร.** คำถามขึ้นต้นด้วยคำถาม what ถามหาสิ่งนั้น which ให้คุณเลือกจากชุด why ถามหาเหตุผล how ถามหาขั้นตอนหรือวิธี แบบฝึกหัดและข้อความผิดพลาดใช้คำเหล่านี้ จึงต้องเข้าใจเพื่อตอบได้
**ทำไมต้องรู้.** ในแบบทดสอบ คำถามบอกชนิดของคำตอบที่ต้องการ คำถาม why ต้องการเหตุผล ไม่ใช่ชื่อ
**ทำอย่างไร.**

หาคำถามก่อน แล้วตัดสินใจว่าคำตอบต้องมีอะไร คือชื่อ ตัวเลือก เหตุผล หรือขั้นตอน ตัวอย่างตอบคำถาม what ด้วยการพิมพ์ค่า
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int width = 6;
    jout << "What is the width? " << width << "\n";
}
```

```
What is the width? 6
```

> **ระวัง:** คำถาม why และ how ต้องการประโยค คำเดียวอย่าง because ไม่พอ และค่าไม่ใช่วิธีการ
**แบบฝึกหัด**
- คำถามใดให้คุณเลือกจากชุดคำตอบ
  - a) what  b) which  c) why  — เฉลย: b. which หมายถึงเลือกหนึ่งจากชุดที่ให้
- คำถามใดถามหาเหตุผล
  - a) how  b) what  c) why  — เฉลย: c. why ถามว่าเกิดขึ้นเพราะอะไร
- คำถาม how ถามหาขั้นตอนของวิธีการ — เฉลย: t. how ถามให้อธิบายว่าสิ่งหนึ่งทำอย่างไร
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int x = 2;
jout << "x is " << x << "\n";
}
```
  ผลลัพธ์ที่ได้: `x is 2`. โปรแกรมพิมพ์ข้อความแล้วตามด้วยค่าของ x
- คำถามที่ถามหาเหตุผลคือ ___ — เฉลย: **why**. why ขอเหตุผล เช่นทำไมลูปจึงหยุด
- ตอบคำถาม how: อ่านคำถาม → หาขั้นตอน → เขียนตามลำดับ → ตรวจว่าคำตอบมีขั้นตอน ไม่ใช่คำเดียว. คำตอบ how ต้องแสดงขั้นตอน จึงตอบเป็นคำเดียวไม่ได้
**โจทย์**
- **ค่าไหน** — เขียนโปรแกรมที่มี int a = 3 และ int b = 8 แล้วพิมพ์คำว่า larger ตามด้วยค่าที่มากกว่า. ผลลัพธ์ที่ได้: `larger 8`. คำใบ้: ใช้ if a > b และ else กับ b

## คำตรงข้าม: before กับ after, true กับ false
**คืออะไร.** คำตรงข้ามบอกสองด้านของกฎ before และ after บอกลำดับของขั้นตอน true และ false คือสองค่าของเงื่อนไข greater และ less คือสองด้านของการเปรียบเทียบ การอ่านด้านตรงข้ามสำคัญเท่ากับการอ่านคำนั้น
**ทำไมต้องรู้.** บั๊กมักมาจากการอ่านผิดด้าน ถ้าคิดว่า after แต่โค้ดทำ before ค่าที่คุณอ่านจะเป็นค่าเก่า
**ทำอย่างไร.**

สำหรับแต่ละเงื่อนไข ถามว่าด้านไหนคือจริง สำหรับแต่ละลำดับ ถามว่าขั้นตอนใดทำก่อน ตัวอย่างพิมพ์ค่าก่อนการเปลี่ยนและค่าหลังการเปลี่ยน
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int x = 1;
    jout << "before " << x << "\n";
    x = x + 5;
    jout << "after " << x << "\n";
}
```

```
before 1
after 6
```

> **ระวัง:** ค่าที่พิมพ์ก่อนการเปลี่ยนไม่ใช่ค่าหลังการเปลี่ยน ให้พิมพ์ตรงจุดที่คุณอยากรู้
**แบบฝึกหัด**
- ในโค้ด การพิมพ์ที่อยู่ก่อนการเปลี่ยนแสดงค่า
  - a) ค่าใหม่  b) ค่าเก่า  c) ค่าสุ่ม  — เฉลย: b. ก่อนการเปลี่ยน ค่ายังเป็นค่าเก่า
- คำตรงข้ามของ true ในเงื่อนไขคือ
  - a) false  b) after  c) zero  — เฉลย: a. false คือค่าอีกด้านของเงื่อนไข
- ถ้าโค้ดพิมพ์หลังจาก x = x + 5 ค่าที่พิมพ์เป็นค่าเก่า — เฉลย: f. หลังการเปลี่ยน ค่าเป็นค่าใหม่
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int n = 2;
n = n * 3;
jout << n << "\n";
}
```
  ผลลัพธ์ที่ได้: `6`. การเปลี่ยนเกิดก่อนการพิมพ์ จึงพิมพ์ค่าใหม่ 6
- คำตรงข้ามของ greater คือ ___ — เฉลย: **less**. greater และ less คือสองด้านของการเปรียบเทียบ
- ติดตามการเปลี่ยนตามลำดับ: เขียนค่าเริ่มต้น → พิมพ์เป็น before → ทำการเปลี่ยน → พิมพ์เป็น after. ลำดับของขั้นตอนบอกว่าแต่ละการพิมพ์เห็นค่าใด
**โจทย์**
- **ก่อนและหลัง** — เขียนโปรแกรมที่มี int y = 4 พิมพ์ before และ y แล้วบวก 2 ให้ y แล้วพิมพ์ after และ y. ผลลัพธ์ที่ได้: `before 4 / after 6`. คำใบ้: พิมพ์ค่าแรก เปลี่ยน y ด้วย y += 2 แล้วพิมพ์อีกครั้ง

## คำเดียว สองความหมาย
**คืออะไร.** หลายคำมีสองความหมายในการเขียนโปรแกรม return อาจหมายถึงส่งค่ากลับจากฟังก์ชัน หรือกลับไปยังที่ที่เรียก count อาจเป็นคำนามคือจำนวน หรือกริยาคือการนับ value อาจหมายถึงสิ่งที่เก็บใต้ชื่อ หรือตัวเลขในช่อง อ่านประโยครอบๆ คำเพื่อหาความหมาย
**ทำไมต้องรู้.** ถ้าอ่าน count เป็นกริยาทั้งที่เป็นคำนาม คุณจะอ่านโค้ดผิด คำรอบๆ ชื่อบอกว่าหมายถึงอะไร
**ทำอย่างไร.**

ดูคำที่อยู่รอบคำนั้น ในคำสั่ง return 0; คำว่า return ส่งค่ากลับ ในคำสั่ง count = count + 1 ชื่อคือตัวเลข ตัวอย่างใช้สองคำคือ count และ return ในฟังก์ชันเดียว
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

int twice(int v) {
    return v * 2;
}

void main() {
    int count = twice(4);
    jout << "count " << count << "\n";
}
```

```
count 8
```

> **ระวัง:** return จบฟังก์ชันที่บรรทัดนั้น บรรทัดที่เขียนหลัง return ในบล็อกเดียวกันจะไม่ทำงาน
**แบบฝึกหัด**
- ใน return v * 2; return ทำอะไร
  - a) หยุดโปรแกรมตลอดไป  b) ส่งค่ากลับจากฟังก์ชัน  c) พิมพ์ค่า  — เฉลย: b. return ให้ค่ากลับแก่ผู้เรียกและออกจากฟังก์ชัน
- ใน count = count + 1 count คืออะไร
  - a) กริยา  b) ชื่อของตัวเลข  c) ประโยค  — เฉลย: b. ที่นี่ count คือชื่อของตัวเลขที่ถูกเปลี่ยน
- คำว่า value หมายถึงข้อความที่พิมพ์เสมอ — เฉลย: f. value คือสิ่งที่เก็บใต้ชื่อ ซึ่งเป็นตัวเลข ข้อความ หรือ struct ก็ได้
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

int twice(int v) {
return v * 2;
}

void main() {
jout << twice(3) << "\n";
}
```
  ผลลัพธ์ที่ได้: `6`. return ส่ง 3 คูณ 2 คือ 6 กลับไปยังผู้เรียก
- คำที่ส่งค่ากลับจากฟังก์ชันคือ ___ — เฉลย: **return**. return จบฟังก์ชันและให้ค่ากลับไป
- อ่านการเรียกฟังก์ชัน: หาชื่อฟังก์ชัน → หาค่าที่ส่งเข้า → หา return ที่ให้ผลลัพธ์ → ใช้ผลลัพธ์. การเรียกส่งค่าเข้า และ return ส่งผลออก
**โจทย์**
- **Return สามเท่า** — เขียนฟังก์ชัน int triple(int v) ที่ return v คูณ 3 แล้วพิมพ์ผลของ 4 พร้อมคำว่า triple นำหน้า. ผลลัพธ์ที่ได้: `triple 12`. คำใบ้: ใช้ return v * 3; และเรียก triple(4) ใน jout

## ประธาน กริยา และกรรม
**คืออะไร.** ประโยคอังกฤษมีประธาน กริยา และกรรม ในบรรทัดโค้ด ประธานมักเป็นชื่อของค่า กริยาคือการกระทำ และกรรมคือสิ่งที่ถูกกระทำ ประโยค Print the count มีกริยา print และกรรม count
**ทำไมต้องรู้.** บรรทัดยาวอ่านยาก ถ้าแยกเป็นประธาน กริยา และกรรม คุณจะเห็นว่าอะไรเปลี่ยนและอะไรเป็นเพียงการอ่าน
**ทำอย่างไร.**

หากริยาก่อน แล้วถามว่ากริยาทำกับอะไร คำตอบคือกรรม ในบรรทัด total = total + n กริยาคือการเปลี่ยนค่า และกรรมคือ total
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int total = 0;
    int n = 5;
    total = total + n;
    jout << total << "\n";
}
```

```
5
```

> **ระวัง:** บรรทัดที่มีสองชื่อเปลี่ยนได้เพียงหนึ่งชื่อ หาชื่อทางซ้ายของเครื่องหมายเท่ากับ นั่นคือกรรมที่เปลี่ยน
**แบบฝึกหัด**
- ใน total = total + n ชื่อใดเปลี่ยน
  - a) n  b) total  c) ทั้งสอง  — เฉลย: b. เฉพาะชื่อทางซ้ายของเครื่องหมายเท่ากับถูกเปลี่ยน n ถูกอ่านเท่านั้น
- ใน print the count กรรมคืออะไร
  - a) print  b) the  c) count  — เฉลย: c. กรรมคือสิ่งที่กริยากระทำ คือ count
- ในบรรทัด x = y ค่าของ y ถูกเปลี่ยน — เฉลย: f. ชื่อทางซ้าย x คือชื่อที่ถูกเปลี่ยน
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int a = 2;
int b = 3;
a = a + b;
jout << a << "\n";
}
```
  ผลลัพธ์ที่ได้: `5`. กรรม a เปลี่ยนเป็น 2 บวก 3 คือ 5
- ในบรรทัดโค้ด ชื่อที่เปลี่ยนอยู่ทางด้าน ___ ของเครื่องหมายเท่ากับ — เฉลย: **ซ้าย**. ชื่อทางซ้ายของ = คือชื่อที่รับค่าใหม่
- อ่านบรรทัดโค้ดเป็นประโยค: หากริยา → หากรรมที่กริยากระทำ → หาประธานที่ทำ → พูดเป็นประโยคภาษาอังกฤษ. กริยามาก่อน แล้วกรรม แล้วประธาน
**โจทย์**
- **เพิ่มชื่อ** — เขียนโปรแกรมที่มี int a = 4 และ int b = 6 เปลี่ยน a เป็น a บวก b แล้วพิมพ์ค่าของ a. ผลลัพธ์ที่ได้: `10`. คำใบ้: ใช้ a = a + b; แล้ว jout

## คำในข้อความผิดพลาด: expected, unknown, missing, cannot
**คืออะไร.** ข้อความของคอมไพเลอร์ใช้คำไม่กี่คำซ้ำๆ expected หมายถึงคอมไพเลอร์ต้องการอย่างอื่นตรงนี้ unknown หมายถึงชื่อนั้นยังไม่ถูกนิยาม missing หมายถึงขาดบางส่วน เช่นเครื่องหมาย ; หรือวงเล็บปีกกา cannot หมายถึงสิ่งนั้นไม่อนุญาต เรียนสี่คำนี้แล้วข้อความส่วนใหญ่จะเข้าใจได้
**ทำไมต้องรู้.** คำแต่ละคำชี้ไปยังการแก้คนละแบบ unknown ต้องนิยามหรือ import missing ต้องเพิ่มอักขระ cannot ต้องเปลี่ยนชนิดหรือแคสต์
**ทำอย่างไร.**

อ่านคำนั้นก่อน แล้วไปที่ตำแหน่งที่ข้อความระบุ สำหรับ unknown ให้ตรวจการสะกดและ import สำหรับ missing ให้ดูท้ายบรรทัดก่อนหน้า สำหรับ cannot ให้อ่านชนิดทั้งสองข้าง ตัวอย่างไม่มีข้อผิดพลาดแต่มีชื่อที่นิยามแล้ว
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int value = 9;
    jout << value << "\n";
}
```

```
9
```

> **ระวัง:** missing มักชี้ช้ากว่าความจริงหนึ่งบรรทัด อักขระที่ขาดมักอยู่ท้ายบรรทัดก่อนบรรทัดที่มีข้อความ
**แบบฝึกหัด**
- ข้อความขึ้นว่า unknown name วิธีแก้ปกติคืออะไร
  - a) เพิ่มเครื่องหมาย ;  b) ตรวจการสะกดและ import  c) เปลี่ยนเป็น double  — เฉลย: b. unknown หมายถึงไม่รู้จักชื่อ จึงตรวจการสะกดและ import ที่นิยามชื่อนั้น
- ข้อความขึ้นว่า missing semicolon ให้มองหาที่ไหนก่อน
  - a) ท้ายบรรทัดก่อนหน้า  b) บรรทัดสุดท้ายของไฟล์  c) ไม่ต้องมอง  — เฉลย: a. อักขระที่ขาดมักอยู่ท้ายบรรทัดก่อนข้อความ
- cannot ในข้อความของคอมไพเลอร์หมายถึงการดำเนินการที่อนุญาตแต่ช้า — เฉลย: f. cannot หมายถึงไม่อนุญาต จึงต้องแก้โค้ด
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int value = 9;
jout << value << "\n";
}
```
  ผลลัพธ์ที่ได้: `9`. ชื่อ value ถูกนิยามแล้ว จึงไม่มี unknown name และพิมพ์ค่า 9
- คำของคอมไพเลอร์ที่หมายถึงชื่อที่ยังไม่ถูกนิยามคือ ___ — เฉลย: **unknown**. unknown หมายถึงชื่อยังไม่ถูกประกาศหรือ import
- แก้ส่วนที่ขาด: อ่านข้อความ → ไปที่บรรทัดก่อนหน้า → เพิ่มอักขระที่ขาด → คอมไพล์ใหม่. คอมไพล์ใหม่หลังแก้แต่ละครั้ง เพื่อดูข้อความถัดไป
**โจทย์**
- **ชื่อที่นิยาม** — เขียนโปรแกรมที่มี int item = 2 และพิมพ์คำว่า item พร้อมค่าของมัน. ผลลัพธ์ที่ได้: `item 2`. คำใบ้: ใช้ jout กับคำ ช่องว่าง และ item

## อ่านหัวข้อและดัชนี
**คืออะไร.** เอกสารมีหัวข้อ คือบรรทัดที่ขึ้นต้นด้วย # หรือ ## และมีดัชนีของคำ หัวข้อบอกเรื่องของบรรทัดที่อยู่ข้างใต้ ดัชนีบอกว่าคำหนึ่งอยู่หน้าไหน การอ่านหัวข้อก่อนช่วยประหยัดเวลา เพราะรู้ว่าเรื่องนั้นตรงกับที่ต้องการหรือไม่
**ทำไมต้องรู้.** บทเรียนและคู่มือภาษายาว ผู้เรียนที่อ่านหัวข้อก่อนหาคำตอบได้ในไม่กี่นาที แทนที่จะอ่านทุกบรรทัด
**ทำอย่างไร.**

อ่านชื่อเรื่องก่อน แล้วอ่านหัวข้อตามลำดับ เลือกหัวข้อที่ตรงกับคำถาม อ่านแล้วค่อยอ่านบรรทัดข้างใต้ เมื่อรู้ชื่อให้ค้นคำนั้นด้วยเครื่องมือค้นหา
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    // heading: printing
    jout << "printing is the first topic\n";
}
```

```
printing is the first topic
```

> **ระวัง:** หัวข้อที่กว้างเกินไป เช่น Notes อาจซ่อนคำตอบ ให้อ่านบรรทัดข้างใต้ก่อนตัดสินว่าหัวข้อไม่ตรง
**แบบฝึกหัด**
- หัวข้อบอกอะไรแก่คุณ
  - a) ราคาของหนังสือ  b) เรื่องของบรรทัดที่อยู่ข้างใต้  c) ชื่อผู้เขียน  — เฉลย: b. หัวข้อคือชื่อเรื่องของส่วนที่อยู่ข้างล่าง
- เมื่อรู้คำ วิธีหาคำนั้นในเอกสารยาวที่เร็วที่สุดคืออะไร
  - a) อ่านทุกบรรทัด  b) ค้นหาคำนั้น  c) เดาหน้า  — เฉลย: b. การค้นหาคำพาไปยังบรรทัดที่ใช้คำนั้นโดยตรง
- หัวข้อไม่บอกอะไรเกี่ยวกับบรรทัดข้างใต้ — เฉลย: f. หัวข้อคือเรื่องของบรรทัดเหล่านั้น จึงช่วยนำการอ่าน
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
// heading: loops
jout << "loops\n";
}
```
  ผลลัพธ์ที่ได้: `loops`. คอมเมนต์ถูกข้าม โปรแกรมพิมพ์ข้อความใน jout
- บรรทัดในเอกสารที่ขึ้นต้นด้วย # คือ ___ — เฉลย: **หัวข้อ**. บรรทัด # คือหัวข้อ และจำนวน # บอกระดับ
- หาคำตอบในบทเรียนยาว: อ่านชื่อเรื่อง → อ่านหัวข้อ → เลือกหัวข้อที่ตรง → อ่านบรรทัดของหัวข้อนั้น. อ่านหัวข้อก่อนข้อความ เพื่อประหยัดเวลา
**โจทย์**
- **พิมพ์หัวข้อ** — เขียนโปรแกรมที่พิมพ์คำว่า heading แล้วคำว่า index. ผลลัพธ์ที่ได้: `heading index`. คำใบ้: ใช้ jout กับสองคำ และช่องว่าง และจบด้วย \n
