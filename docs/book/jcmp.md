# Jcmp

## jcmp ทำอะไร
**คืออะไร.** jcmp คือคอมไพเลอร์ของ J2K มันอ่านไฟล์โค้ดที่ลงท้ายด้วย .jk ตรวจทุกบรรทัด แล้วเขียนโปรแกรมที่คอมพิวเตอร์รันได้ ถ้าการตรวจไม่ผ่าน มันพิมพ์ข้อความที่มีไฟล์ บรรทัด และคอลัมน์ และจะไม่เขียนโปรแกรมใหม่
**ทำไมต้องรู้.** ทุกโปรแกรมของ J2K ผ่าน jcmp ทุกครั้งที่คุณแก้บรรทัด จึงควรรู้ว่ามันทำอะไรกับไฟล์ และข้อความของมันหมายความว่าอะไร
**ทำอย่างไร.**

เขียนไฟล์ แล้วสั่งคอมไพล์ด้วยชื่อผลลัพธ์หลัง -o แล้วรันผลลัพธ์ ขั้นตอนคือ เขียน hello.jk รัน jcmp hello.jk -o hello แล้วรัน ./hello ตัวอย่างด้านล่างคือโปรแกรมทั้งหมด
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    jout << "compiled and running\n";
}
```

```
compiled and running
```

> **ระวัง:** การรันโปรแกรมเก่าหลังคอมไพล์ล้มเหลวเป็นข้อผิดพลาดที่พบบ่อย ถ้า jcmp แสดง error จะไม่มีโปรแกรมใหม่ไฟล์เก่ายังอยู่และซ่อนปัญหาไว้
**แบบฝึกหัด**
- jcmp ทำอะไรกับไฟล์ hello.jk
  - a) รันโปรแกรมในไฟล์  b) ตรวจไฟล์และเขียนโปรแกรม  c) ลบไฟล์  — เฉลย: b. jcmp ตรวจทุกบรรทัดแล้วเขียนโปรแกรม การรันเป็นขั้นตอนแยก
- ตัวเลือกใดตั้งชื่อผลลัพธ์เป็น hello
  - a) -name hello  b) -o hello  c) -out=hello  — เฉลย: b. ตัวเลือก -o ตั้งชื่อไฟล์ผลลัพธ์ ถ้าไม่ระบุ ชื่อจะขึ้นกับชื่อไฟล์ต้นทาง
- ถ้า jcmp พบ error มันยังเขียนไฟล์โปรแกรมใหม่ — เฉลย: f. เมื่อมี error จะไม่เขียนโปรแกรมใหม่ ดังนั้นไฟล์เก่าที่ชื่อเดียวกันอาจยังอยู่
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << "a" << "\n";
jout << "b";
}
```
  ผลลัพธ์ที่ได้: `a / b`. jout แต่ละอันพิมพ์ข้อความของมัน อันแรกจบด้วยขึ้นบรรทัดใหม่ อันที่สองพิมพ์ b โดยไม่ขึ้นบรรทัดใหม่
- ตัวเลือกที่ตั้งชื่อไฟล์ผลลัพธ์คือ -___ — เฉลย: **o**. jcmp hello.jk -o hello เขียนโปรแกรมชื่อ hello
- สร้างและรันโปรแกรมแรก: เขียน hello.jk → รัน jcmp hello.jk -o hello → รัน ./hello → อ่านผลที่พิมพ์. ไฟล์ต้องมีก่อน และการคอมไพล์ต้องสำเร็จก่อนรัน
**โจทย์**
- **สองคำ** — เขียนโปรแกรมที่พิมพ์ hello แล้ว world โดยแต่ละคำอยู่คนละบรรทัด. ผลลัพธ์ที่ได้: `hello / world`. คำใบ้: ใช้ jout หนึ่งอันต่อหนึ่งคำ และจบแต่ละอันด้วย \n

## โปรแกรมกับคอมโพเนนต์
**คืออะไร.** J2K มีไฟล์สองชนิด ไฟล์ที่ลงท้ายด้วย .jk คือโปรแกรม ต้องมีฟังก์ชัน main ซึ่งเป็นจุดเริ่มต้น ไฟล์ที่ลงท้ายด้วย .j คือคอมโพเนนต์ ไฟล์อื่นนำเข้าด้วย #import คอมโพเนนต์ห้ามมี main
**ทำไมต้องรู้.** โปรแกรมขนาดใหญ่แบ่งเป็นหลายไฟล์ คอมโพเนนต์เก็บโค้ดที่หลายโปรแกรมใช้ร่วมกัน ส่วนโปรแกรมมี main การรู้ว่าไฟล์ไหนเป็นอะไรช่วยไม่ให้เจอข้อความว่า main หายไป
**ทำอย่างไร.**

ใส่ main ไว้ในไฟล์ .jk ใส่ฟังก์ชันที่ใช้ร่วมกันไว้ในไฟล์ .j แล้วนำเข้าไฟล์นั้นตรงที่ต้องใช้ ตัวอย่างเป็นโปรแกรมที่สมบูรณ์ซึ่งใช้ไลบรารีมาตรฐาน
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    jout << "main is the start\n";
}
```

```
main is the start
```

> **ระวัง:** การใส่ main ไว้ในไฟล์ .j เป็นความผิดพลาด ให้เปลี่ยนชื่อไฟล์เป็น .jk หรือย้าย main ไปไฟล์โปรแกรมที่นำเข้าคอมโพเนนต์
**แบบฝึกหัด**
- ไฟล์ใดต้องมี main
  - a) ไฟล์ .j  b) ไฟล์ .jk  c) ไฟล์ที่ไม่มีชื่อ  — เฉลย: b. โปรแกรมคือไฟล์ .jk คอมโพเนนต์ (.j) กำหนด main ไม่ได้
- บรรทัดใดนำไลบรารีเข้ามาในไฟล์
  - a) using stdlib;  b) #import <stdlib>  c) jout << x;  — เฉลย: b. #import โหลดไลบรารี using stdlib ทำให้ชื่อใช้ได้โดยไม่ต้องมีคำนำหน้า
- คอมโพเนนต์ (ไฟล์ .j) เป็นโปรแกรมที่รันเองได้ — เฉลย: f. คอมโพเนนต์ถูกนำเข้าโดยไฟล์อื่น และไม่รันเอง
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << "start\n";
}
```
  ผลลัพธ์ที่ได้: `start`. โปรแกรมเริ่มใน main และพิมพ์ข้อความหนึ่งครั้ง
- นามสกุลไฟล์ของโปรแกรมคือ .___ — เฉลย: **jk**. โปรแกรมลงท้ายด้วย .jk ส่วนคอมโพเนนต์ลงท้ายด้วย .j
- แยกโค้ดเป็นสองไฟล์: เขียนฟังก์ชันที่ใช้ร่วมในไฟล์ .j → ใส่ main ในไฟล์ .jk → นำเข้าไฟล์ .j ในไฟล์ .jk → คอมไพล์ไฟล์ .jk. ต้องเขียนคอมโพเนนต์ก่อน โปรแกรมจึงนำเข้าได้
**โจทย์**
- **ข้อความเริ่ม** — เขียนโปรแกรมที่พิมพ์ข้อความว่า main runs first. ผลลัพธ์ที่ได้: `main runs first`. คำใบ้: ใช้ jout กับข้อความและจบด้วย \n

## ชนิดจำนวนเต็ม: int, i32, i8
**คืออะไร.** ชนิดจำนวนเต็มเก็บเลขจำนวนเต็ม int มี 64 บิต i32 มี 32 บิต และ i8 มี 8 บิต ทุกชนิดมีเครื่องหมาย จึงเก็บค่าติดลบได้ ขนาดบอกว่าค่าที่ใหญ่ที่สุดที่ชนิดนั้นเก็บได้คือเท่าไร
**ทำไมต้องรู้.** ค่าที่ใหญ่เกินชนิดจะถูกตัดให้พอดี ผลลัพธ์จึงไม่เป็นอย่างที่คาด และบั๊กนี้มองเห็นยาก การรู้ขนาดป้องกันปัญหานี้ได้
**ทำอย่างไร.**

เลือกชนิดตามขนาดของค่า เมื่อเก็บค่าลงชนิดเล็ก ค่าจะถูกตัดให้เท่าขนาดนั้น การบวกทำที่ความกว้างเต็ม แต่ค่าจะถูกตัดตอนเก็บ ตัวอย่างแสดงด้วย i8
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    i8 a = 100;
    i8 b = 100;
    int sum = a + b;
    i8 small = a + b;
    jout << sum << "\n";
    jout << small << "\n";
}
```

```
200
-56
```

> **ระวัง:** ผลของ i8 + i8 คือ int ระหว่างการบวก การตัดเกิดเมื่อผลรวมถูกเก็บลง i8 ถ้าต้องการค่าเต็มให้เก็บลง int
**แบบฝึกหัด**
- ขนาดของ int ใน J2K คือเท่าไร
  - a) 8 บิต  b) 32 บิต  c) 64 บิต  — เฉลย: c. int มี 64 บิต i32 มี 32 บิต และ i8 มี 8 บิต
- i8 เก็บได้ถึง 127 ถ้าเก็บ 200 ลง i8 จะเกิดอะไร
  - a) ค่าถูกตัดให้พอดี  b) คอมไพเลอร์หยุด  c) ค่ายังเป็น 200  — เฉลย: a. ค่าถูกตัดเป็น 8 บิตตอนเก็บ จึงไม่คงเป็น 200
- i8 เก็บเลขติดลบได้ — เฉลย: t. ชนิดที่มีเครื่องหมายทุกชนิดเก็บค่าติดลบได้
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
i8 x = 127;
int y = x + 1;
jout << y << "\n";
}
```
  ผลลัพธ์ที่ได้: `128`. การบวกทำที่ความกว้างเต็ม 127 บวก 1 เป็น 128 ใน int
- ชนิดที่ 64 บิตและมีเครื่องหมายคือ ___ — เฉลย: **int**. int เป็นชนิดจำนวนเต็มปกติของ J2K
- เก็บเลขใหญ่ลง i8: เขียนตัวเลข → เก็บลง i8 → ค่าถูกตัดเป็น 8 บิต → อ่านค่าที่เก็บไว้. การตัดเกิดตอนเก็บ จึงเป็นขั้นตอนเก็บที่เปลี่ยนค่า
**โจทย์**
- **เก็บค่าเล็ก** — เขียนโปรแกรมที่เก็บ 200 ลง i8 แล้วพิมพ์. ผลลัพธ์ที่ได้: `-56`. คำใบ้: 200 ถูกตัดเป็น 8 บิต นึกถึงช่วง 8 บิตคือตั้งแต่ -128 ถึง 127

## ชนิดไม่มีเครื่องหมาย: u8, u32, u64
**คืออะไร.** ชนิดไม่มีเครื่องหมายเก็บได้เฉพาะศูนย์และจำนวนบวก u8 มี 8 บิต u32 มี 32 บิต และ u64 มี 64 บิต เพราะไม่มีเครื่องหมาย บิตชุดเดียวกันจึงเก็บค่าบวกที่มากกว่าได้ u8 เก็บได้ 0 ถึง 255
**ทำไมต้องรู้.** ไบต์ แฮช และบิตมาสก์มักเป็นไม่มีเครื่องหมาย ถ้าผสมค่ามีเครื่องหมายกับไม่มีเครื่องหมาย คอมไพเลอร์จะขอให้แคสต์ จึงไม่ผสมโดยบังเอิญ
**ทำอย่างไร.**

ใช้ชนิดไม่มีเครื่องหมายเมื่อค่าไม่เคยติดลบ เปรียบเทียบ หาร และเลื่อนบิตขวาเป็นจำนวนไม่มีเครื่องหมาย แคสต์ระหว่างมีและไม่มีเครื่องหมายด้วย (u32)n หรือ (int)x เมื่อตั้งใจ ตัวอย่างบวกค่าลง u8 แล้วแสดงการตัด
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    u8 b = 250;
    b += 10;
    jout << b << "\n";
}
```

```
4
```

> **ระวัง:** -1 ใส่ในชนิดไม่มีเครื่องหมายไม่ได้ ค่าติดลบต้องแคสต์ไม่เช่นนั้นเป็น error การแคสต์ไม่เปลี่ยนบิต เพียงเปลี่ยนวิธีอ่านบิตนั้น
**แบบฝึกหัด**
- u8 เก็บค่ามากที่สุดได้เท่าไร
  - a) 127  b) 255  c) 256  — เฉลย: b. u8 มี 8 บิตและไม่มีเครื่องหมาย จึงเก็บได้ 0 ถึง 255
- ทำไมคอมไพเลอร์หยุดเมื่อผสม int กับ u32 ในผลรวมเดียว
  - a) เพราะชื่อยาวเกินไป  b) เพราะเครื่องหมายไม่ตรงกันและต้องแคสต์  c) เพราะ u32 ช้า  — เฉลย: b. การผสมค่ามีเครื่องหมายกับไม่มีเครื่องหมายต้องแคสต์ เพื่อให้เจตนาชัดเจน
- b += 10 ของ u8 ที่เก็บ 250 ทำให้ตัวแปรเก็บ 260 — เฉลย: f. 260 ถูกตัดเป็น 8 บิตตอนเก็บ ตัวแปรจึงเก็บ 4
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
u8 b = 255;
b += 1;
jout << b << "\n";
}
```
  ผลลัพธ์ที่ได้: `0`. 255 บวก 1 เป็น 256 และการตัดเป็น 8 บิตได้ 0
- ชนิดไม่มีเครื่องหมายเขียนด้วยตัว u เช่น u___ — เฉลย: **8**. u8 เก็บเลขตั้งแต่ 0 ถึง 255
- บวกค่าไม่มีเครื่องหมาย: ประกาศ u8 พร้อมค่า → บวกด้วย += → ผลถูกตัดเป็น 8 บิตตอนเก็บ → พิมพ์ค่า. การตัดเป็นส่วนของการเก็บ จึงเกิดในขั้นสุดท้าย
**โจทย์**
- **ค่าวน** — เขียนโปรแกรมที่มี u8 b = 250 บวก 10 ให้ b แล้วพิมพ์คำว่า wrap ตามด้วย b. ผลลัพธ์ที่ได้: `wrap 4`. คำใบ้: ใช้ b += 10 แล้ว jout กับข้อความ ช่องว่าง และ b

## ทศนิยม: float และ double
**คืออะไร.** จำนวนทศนิยมมีส่วนหลังจุด เช่น 2.5 float คือชนิด 32 บิต ส่วน double คือชนิด 64 บิต double เก็บหลักได้มากกว่า int กับ float ผสมกันในนิพจน์เดียวไม่ได้โดยไม่แคสต์ จึงต้องแปลงค่าเอง
**ทำไมต้องรู้.** เงิน ระยะวัด และค่าเฉลี่ยต้องใช้ทศนิยม การเลือก double ให้หลักมากกว่า การหารจำนวนเต็มสองค่าได้จำนวนเต็ม จึงต้องมีตัวหนึ่งเป็น double
**ทำอย่างไร.**

เขียนเลขทศนิยมเช่น 2.5 ก็เป็น double เพื่อหารจำนวนเต็มเป็นทศนิยม ให้แคสต์ค่าหนึ่งด้วย (double) ตัวอย่างแคสต์ n ก่อนหาร ผลจึงมีส่วนทศนิยม
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int n = 7;
    double half = (double)n / 2.0;
    jout << half << "\n";
}
```

```
3.500000
```

> **ระวัง:** 7 / 2 ของจำนวนเต็มสองค่าได้ 3 ไม่ใช่ 3.5 ส่วนทศนิยมหายไปเมื่อทั้งสองข้างเป็นจำนวนเต็ม
**แบบฝึกหัด**
- float กับ double ต่างกันอย่างไร
  - a) float มี 64 บิต และ double มี 32 บิต  b) float มี 32 บิต และ double มี 64 บิต  c) ไม่ต่างกัน  — เฉลย: b. float เป็นชนิด 32 บิต และ double เป็น 64 บิตซึ่งเก็บหลักได้มากกว่า
- ทำไม 7 / 2 ของจำนวนเต็มสองค่าได้ 3
  - a) เพราะ 7 เป็นเลขคี่  b) เพราะการหารจำนวนเต็มตัดส่วนทศนิยมทิ้ง  c) เพราะคอมไพเลอร์ผิด  — เฉลย: b. การหารจำนวนเต็มเก็บเฉพาะส่วนจำนวนเต็มของคำตอบ
- double กับ int บวกกันได้โดยไม่ต้องแคสต์ — เฉลย: f. int กับ float ผสมในนิพจน์เดียวไม่ได้โดยไม่แคสต์ ให้แคสต์ข้างหนึ่งด้วย (double)
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int a = 5;
jout << (double)a / 2.0 << "\n";
}
```
  ผลลัพธ์ที่ได้: `2.500000`. การแคสต์ทำให้เป็น double ดังนั้น 5 หาร 2 ได้ 2.5
- เพื่อแปลง int เป็น double เขียน (___)n — เฉลย: **double**. (double)n ให้ค่าเป็นเลขทศนิยมก่อนการหาร
- หารและพิมพ์ทศนิยม: เขียนค่า int → แคสต์ค่าหนึ่งเป็น double → หาร → พิมพ์ผลลัพธ์. การแคสต์มาก่อนการหาร ไม่ใช่หลังจากนั้น
**โจทย์**
- **ค่าเฉลี่ย** — เขียนโปรแกรมที่มี int total = 9 และ int count = 2 แล้วพิมพ์คำว่า avg ตามด้วยค่าเฉลี่ยเป็น double. ผลลัพธ์ที่ได้: `avg 4.500000`. คำใบ้: ใช้ (double)total / (double)count ในวงเล็บของ jout

## แคสต์: เปลี่ยนชนิดโดยตั้งใจ
**คืออะไร.** การแคสต์เปลี่ยนชนิดของค่าด้วยวงเล็บ เช่น (int)x หรือ (double)n คุณเขียนเมื่อต้องการการเปลี่ยนนั้น ไม่เช่นนั้นคอมไพเลอร์จะปฏิเสธ การแคสต์บอกคอมไพเลอร์ว่าคุณรู้สิ่งที่ทำ
**ทำไมต้องรู้.** ถ้าไม่มีการแคสต์ การผสมชนิดเป็น error เมื่อมีการแคสต์ คุณบอกชัดว่าการเปลี่ยนเกิดตรงไหน ผู้อ่านจึงเห็นและตรวจได้
**ทำอย่างไร.**

เขียนชนิดในวงเล็บหน้าค่า การแคสต์ใช้กับค่าที่อยู่ติดหลังมัน (double)n / 2.0 แคสต์ n ก่อนแล้วจึงหาร ตัวอย่างแสดงการแคสต์จาก float เป็น int ซึ่งตัดส่วนทศนิยม
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    double x = 3.9;
    int whole = (int)x;
    jout << whole << "\n";
}
```

```
3
```

> **ระวัง:** (int)3.9 ได้ 3 ไม่ใช่ 4 การแคสต์เป็น int ตัดส่วนทศนิยมทิ้ง ไม่ได้ปัดเศษ
**แบบฝึกหัด**
- (int)3.9 มีค่าเท่าไร
  - a) 4  b) 3  c) 3.9  — เฉลย: b. การแคสต์เป็น int ตัดส่วนทศนิยมทิ้ง ไม่ได้ปัดเศษ
- ใน (double)n / 2.0 ส่วนใดทำก่อน
  - a) การหาร  b) การแคสต์ n  c) การพิมพ์  — เฉลย: b. การแคสต์ผูกกับ n จึงแปลง n เป็น double ก่อนการหาร
- ต้องแคสต์เพื่อผสมค่ามีเครื่องหมายกับไม่มีเครื่องหมายในนิพจน์เดียว — เฉลย: t. การผสมค่ามีและไม่มีเครื่องหมายเป็น error จนกว่าจะแคสต์ข้างหนึ่ง
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int n = -1;
u32 back = (u32)n;
jout << back << "\n";
}
```
  ผลลัพธ์ที่ได้: `4294967295`. การแคสต์อ่านบิต 32 บิตเดิมเป็นค่าไม่มีเครื่องหมาย ได้ค่าสูงสุดของ u32
- การแคสต์เป็น int เขียนด้วยคำว่า ___ ในวงเล็บ — เฉลย: **int**. (int)x เปลี่ยน x เป็น int และตัดส่วนทศนิยมทิ้ง
- แคสต์ค่าและพิมพ์: เขียนค่าพร้อมชนิด → ใส่ชนิดใหม่ในวงเล็บหน้าค่า → ใช้ค่าที่แคสต์แล้วในนิพจน์ → พิมพ์ผลลัพธ์. การแคสต์เขียนติดกับค่าที่มันเปลี่ยน
**โจทย์**
- **แคสต์ลง** — เขียนโปรแกรมที่มี double d = 8.8 แล้วพิมพ์ส่วนจำนวนเต็มด้วยการแคสต์เป็น int โดยมีคำว่า whole นำหน้า. ผลลัพธ์ที่ได้: `whole 8`. คำใบ้: ใช้ (int)d ในวงเล็บของ jout

## ข้อความและการขึ้นบรรทัดใหม่
**คืออะไร.** สตริงคือข้อความในเครื่องหมายคำพูด เช่น "hi" การขึ้นบรรทัดใหม่ในสตริงเขียนเป็น \n คือแบ็กสแลชกับตัว n คำว่า nl ทำงานเหมือนกันโดยไม่ต้องมีแบ็กสแลช ส่วน /n คือเครื่องหมายทับกับตัว n ไม่ใช่การขึ้นบรรทัดใหม่ และคอมไพเลอร์จะเตือน
**ทำไมต้องรู้.** ผลลัพธ์ที่ขึ้นบรรทัดผิดดูเสียหาย คำเตือนเรื่อง /n บอกความผิดพลาดตอนพิมพ์ที่พลาดง่าย
**ทำอย่างไร.**

เขียน \n ท้ายข้อความ หรือเขียน nl หลังค่า ตัวอย่างแสดงทั้งสองวิธีในโปรแกรมเดียว
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    jout << "first\n";
    jout << "second" << nl;
}
```

```
first
second
```

> **ระวัง:** ถ้าพิมพ์ /n แทน \n คอมไพเลอร์จะเตือนว่าเป็นเครื่องหมายทับกับตัว n บรรทัดจะพิมพ์ /n ออกมาและไม่ขึ้นบรรทัดใหม่
**แบบฝึกหัด**
- โค้ดใดทำให้ขึ้นบรรทัดใหม่ในสตริง
  - a) "/n"  b) "\n"  c) "new line"  — เฉลย: b. \n คือแบ็กสแลชกับ n ทำให้ขึ้นบรรทัดใหม่ /n คือเครื่องหมายทับกับ n ไม่ใช่การขึ้นบรรทัด
- nl ใน jout << x << nl; ทำอะไร
  - a) พิมพ์คำว่า nl  b) ขึ้นบรรทัดใหม่  c) หยุดโปรแกรม  — เฉลย: b. nl ไม่ต้องใช้แบ็กสแลช มันขึ้นบรรทัดใหม่หลังค่า
- ค่าเดียวใน jout << x; ได้บรรทัดใหม่เองโดยไม่ต้องใช้ \n — เฉลย: t. jout พิมพ์ค่าเดียวและขึ้นบรรทัดใหม่ท้ายให้ จึงไม่ต้องใช้ \n สำหรับค่าเดียว
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << "a" << nl;
jout << "b" << "\n";
}
```
  ผลลัพธ์ที่ได้: `a / b`. แต่ละบรรทัดจบด้วยการขึ้นบรรทัดใหม่ ทั้ง nl และ \n ทำให้ขึ้นบรรทัดได้
- คำที่ขึ้นบรรทัดใหม่โดยไม่ต้องมีแบ็กสแลชคือ ___ — เฉลย: **nl**. jout << x << nl; พิมพ์ x แล้วขึ้นบรรทัดใหม่
- พิมพ์ข้อความสองบรรทัด: เขียน jout แรกพร้อมข้อความและ \n → เขียน jout ที่สองพร้อมข้อความ → คอมไพล์ → รันและอ่านบรรทัด. jout แต่ละอันคือหนึ่งบรรทัดตามลำดับที่เขียน
**โจทย์**
- **สองบรรทัด** — เขียนโปรแกรมที่พิมพ์ one แล้วขึ้นบรรทัดใหม่แล้วพิมพ์ two โดยใช้ nl. ผลลัพธ์ที่ได้: `one / two`. คำใบ้: ใช้ jout << "one" << nl; และ jout << "two" << nl;

## อ่านข้อผิดพลาดของคอมไพเลอร์
**คืออะไร.** ข้อผิดพลาดของคอมไพเลอร์มีรูปแบบ ไฟล์:บรรทัด:คอลัมน์: error: ข้อความ ชื่อไฟล์คือไฟล์ต้นทาง บรรทัดและคอลัมน์คือตำแหน่ง ส่วนข้อความบอกว่าผิดอะไร ข้อความคือเหตุผล และตำแหน่งบอกว่าต้องดูตรงไหน
**ทำไมต้องรู้.** ข้อผิดพลาดคือสิ่งที่คุณอ่านบ่อยที่สุด คอมไพเลอร์ให้ตำแหน่งเสมอ วิธีแก้โปรแกรมที่เร็วที่สุดคือไปที่ตำแหน่งนั้นและอ่านข้อความทีละคำ
**ทำอย่างไร.**

ไปที่บรรทัดก่อน อ่านข้อความและหาคำที่บอกปัญหา เช่น unknown name หรือ type แก้ทีละอย่าง แล้วคอมไพล์ใหม่ อย่าแก้หลายอย่างพร้อมกัน ไม่เช่นนั้นจะไม่รู้ว่าการแก้ไหนได้ผล
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int count = 3;
    jout << count << "\n";
}
```

```
3
```

> **ระวัง:** อย่าเริ่มแก้ error ที่สอง error แรกมักทำให้เกิดข้อความที่ตามมา ให้แก้ข้อความแรกแล้วคอมไพล์ใหม่
**แบบฝึกหัด**
- ใน main.jk:4:9: error: unknown name ตำแหน่งของปัญหาคืออะไร
  - a) ไฟล์ main.jk บรรทัด 4 คอลัมน์ 9  b) บรรทัด 9  c) คำว่า error  — เฉลย: a. ตำแหน่งคือไฟล์:บรรทัด:คอลัมน์ ปัญหาอยู่ที่บรรทัด 4 คอลัมน์ 9 ของ main.jk
- เมื่อมีหลาย error ควรแก้อันไหนก่อน
  - a) อันสุดท้าย  b) อันแรก  c) อันไหนก็ได้  — เฉลย: b. error แรกมักทำให้อันถัดไปเกิด จึงแก้อันแรกแล้วคอมไพล์ใหม่
- คำเตือนในข้อความหมายว่าโปรแกรมไม่ถูกสร้าง — เฉลย: f. คำเตือนไม่หยุดการสร้าง มันบอกว่าอาจมีอะไรผิด
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int count = 3;
jout << count << "\n";
}
```
  ผลลัพธ์ที่ได้: `3`. count เก็บ 3 และ jout พิมพ์ออกมาพร้อมขึ้นบรรทัดใหม่
- รูปแบบข้อความคือ ไฟล์ แล้วบรรทัด แล้ว ___ คั่นด้วยเครื่องหมายสองจุด — เฉลย: **คอลัมน์**. file:line:col คือตำแหน่งของข้อความ
- แก้ข้อผิดพลาดของคอมไพเลอร์: อ่านข้อความแรก → ไปที่ตำแหน่งที่ระบุ → แก้หนึ่งอย่าง → คอมไพล์ใหม่. การแก้ทีละอย่างแสดงว่าการแก้ไหนทำให้ปัญหาหาย
**โจทย์**
- **แก้การพิมพ์** — เขียนโปรแกรมที่พิมพ์ตัวเลข 10 พร้อมขึ้นบรรทัดใหม่. ผลลัพธ์ที่ได้: `10`. คำใบ้: ใช้ jout << 10 << "\n"; ใน main

## bool และ if: bool ไม่ใช่ตัวเลข
**คืออะไร.** bool คือชนิดของค่าใช่หรือไม่ใช่ มีสองค่าคือ true และ false และกินหนึ่งไบต์ คำสั่ง if ต้องการ bool ตัวเลขไม่ใช่ bool ดังนั้น if n เป็น error เมื่อ n เป็น int ต้องเขียน if n != 0 เพื่อถามคำถาม
**ทำไมต้องรู้.** ภาษาหลายภาษาให้เขียน if n ได้และถือว่าเลขทุกตัวเป็นใช่ J2K ให้คุณเขียนคำถามเอง ผู้อ่านจึงเห็นเงื่อนไขทันที
**ทำอย่างไร.**

เก็บผลการเปรียบเทียบไว้ใน bool หรือเขียนการเปรียบเทียบหลัง if โดยตรง ตัวอย่างเก็บการเปรียบเทียบใน bool แล้วใช้กับ if จากนั้นตรวจ int กับศูนย์ด้วย != เพื่อถามคำถาม
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    bool ok = 7 > 3;
    if ok { jout << "yes\n"; }
    int n = 0;
    if n != 0 { jout << "not zero\n"; } else { jout << "zero\n"; }
}
```

```
yes
zero
```

> **ระวัง:** if n เมื่อ n เป็น int คือ error ให้เขียน if n != 0 เพื่อบอกสิ่งที่ตั้งใจ เพราะตัวเลขไม่ใช่ค่าใช่หรือไม่ใช่
**แบบฝึกหัด**
- bool มีขนาดเท่าไร
  - a) หนึ่งบิต  b) หนึ่งไบต์  c) สี่ไบต์  — เฉลย: b. bool กินหนึ่งไบต์และเก็บ true หรือ false
- บรรทัดใดถูกต้องเมื่อ n เป็น int
  - a) if n { ... }  b) if n != 0 { ... }  c) if (n) = 0 { ... }  — เฉลย: b. if ต้องการ bool และ n != 0 คือการเปรียบเทียบที่ให้ bool
- ใน J2K ใช้ตัวเลขเป็นเงื่อนไขของ if ได้โดยตรง — เฉลย: f. bool ไม่ใช่ตัวเลข ต้องเปรียบเทียบตัวเลขก่อนเพื่อให้เงื่อนไขเป็น bool
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
bool b = 2 == 2;
if b { jout << "same\n"; }
}
```
  ผลลัพธ์ที่ได้: `same`. การเปรียบเทียบ 2 == 2 เป็นจริง bool จึงเก็บ true และ if พิมพ์
- ค่าสองค่าของ bool คือ true และ ___ — เฉลย: **false**. bool คือค่าใช่หรือไม่ใช่ที่มีสองค่า
- ใช้การเปรียบเทียบใน if: เขียนการเปรียบเทียบ → ใส่หลัง if หรือใน bool → เขียนบล็อกด้วย jout → เพิ่ม else สำหรับอีกกรณี. การเปรียบเทียบให้ bool ที่ if ต้องการ
**โจทย์**
- **ตรวจบวก** — เขียนโปรแกรมที่มี int n = 4 ถ้า n > 0 เป็นจริงพิมพ์ positive ไม่เช่นนั้นพิมพ์ no. ผลลัพธ์ที่ได้: `positive`. คำใบ้: ใช้ if n > 0 กับ jout และ else กับ jout อีกอัน

## char: อักขระหนึ่งตัวหรือหนึ่งไบต์
**คืออะไร.** char คือชนิดไม่มีเครื่องหมายขนาด 8 บิตที่เก็บอักขระหนึ่งตัวหรือหนึ่งไบต์ เขียนในเครื่องหมายคำพูดเดี่ยว เช่น 'A' เป็น char ที่มีค่า 65 char พิมพ์เป็นตัวอักษร ส่วน u8 พิมพ์เป็นตัวเลข การคำนวณกับ char ได้ int และถ้าเก็บผลลงใน char จะถูกตัดเหลือ 8 บิต
**ทำไมต้องรู้.** ข้อความถูกอ่านทีละอักขระ ถ้าสับสน char กับ u8 หรือกับสตริง อักขระจะพิมพ์เป็นตัวเลขและผลผิด
**ทำอย่างไร.**

เขียนอักขระในเครื่องหมายคำพูดเดี่ยว ใช้ char สำหรับอักขระเดียว และใช้สตริงสำหรับข้อความ ตัวอย่างบวก 1 ให้ char เพื่อได้ตัวอักษรถัดไป แล้วเก็บกลับลง char
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    char letter = 'A';
    char next = letter + 1;
    jout << letter << " " << next << "\n";
}
```

```
A B
```

> **ระวัง:** เครื่องหมายคำพูดคู่ทำสตริง และเครื่องหมายคำพูดเดี่ยวทำ char 'A' กับ "A" ไม่ใช่ชนิดเดียวกัน
**แบบฝึกหัด**
- 'A' เก็บอะไรใน J2K
  - a) ข้อความ A  b) char ที่มีค่า 65  c) ตัวเลข 1  — เฉลย: b. เครื่องหมายคำพูดเดี่ยวทำ char และรหัสของ A คือ 65
- ชนิดใดพิมพ์ตัวอักษรเมื่อพิมพ์ค่า
  - a) u8  b) char  c) i32  — เฉลย: b. char พิมพ์เป็นอักษร ส่วน u8 พิมพ์เป็นตัวเลข
- 'A' กับ "A" เป็นชนิดเดียวกัน — เฉลย: f. เครื่องหมายคำพูดเดี่ยวให้ char ส่วนคู่ให้สตริง
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
char c = 'a';
jout << c << "\n";
}
```
  ผลลัพธ์ที่ได้: `a`. char พิมพ์เป็นอักขระของมัน จึงพิมพ์ตัว a
- อักขระหนึ่งตัวใน J2K เขียนในเครื่องหมายคำพูด ___ — เฉลย: **เดี่ยว**. 'A' ใช้เครื่องหมายคำพูดเดี่ยว และ "A" ใช้คู่สำหรับสตริง
- พิมพ์ตัวอักษรถัดไป: เขียน char ด้วย 'A' → บวก 1 → เก็บผลลง char → พิมพ์ char. ต้องเก็บผลการบวกก่อนจึงพิมพ์เป็น char ได้
**โจทย์**
- **ตัวถัดไป** — เขียนโปรแกรมที่มี char c = 'C' แล้วพิมพ์ตัวอักษรที่อยู่ถัดจากนั้น. ผลลัพธ์ที่ได้: `D`. คำใบ้: บวก 1 ให้ c แล้วเก็บลง char จากนั้นพิมพ์

## การหารจำนวนเต็มและเศษ %
**คืออะไร.** การหารค่า int สองค่าได้ int ส่วนเศษทศนิยมถูกทิ้ง 17 / 5 ได้ 3 ตัวดำเนินการ % ให้เศษที่เหลือ 17 % 5 ได้ 2 ทั้งสองแยกเลขเป็นส่วนจำนวนเต็มและส่วนที่เหลือ
**ทำไมต้องรู้.** นาฬิกา จำนวนหน้า และการตรวจเลขคู่ใช้การหารและเศษ เศษเป็นศูนย์หมายความว่าหารลงตัว
**ทำอย่างไร.**

ใช้ / เพื่อหาว่าเลขหนึ่งเข้าอีกเลขกี่ครั้ง และใช้ % เพื่อหาเศษ ตัวอย่างพิมพ์ทั้งสองค่าของ 17 และ 5
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int a = 17;
    jout << a / 5 << " " << a % 5 << "\n";
}
```

```
3 2
```

> **ระวัง:** การหารด้วยศูนย์เป็น error ตอนรัน ให้ตรวจว่าตัวหารไม่เป็นศูนย์ก่อนหาร
**แบบฝึกหัด**
- 17 / 5 ของ int สองค่าได้เท่าไร
  - a) 3.4  b) 3  c) 4  — เฉลย: b. การหารจำนวนเต็มทิ้งส่วนทศนิยม คำตอบจึงเป็น 3
- 17 % 5 เท่ากับเท่าไร
  - a) 3  b) 2  c) 0  — เฉลย: b. เศษของ 17 หารด้วย 5 คือ 2
- เลขเป็นเลขคู่เมื่อ n % 2 เป็น 0 — เฉลย: t. เลขคู่หารด้วย 2 ลงตัว เศษจึงเป็น 0
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << 10 % 4 << "\n";
}
```
  ผลลัพธ์ที่ได้: `2`. 10 หารด้วย 4 ได้ 2 เหลือเศษ 2
- ตัวดำเนินการที่ให้เศษของการหารคือ ___ — เฉลย: **%**. เครื่องหมายเปอร์เซ็นต์ให้เศษหลังการหารจำนวนเต็ม
- แบ่งจำนวนหน้า: เขียนจำนวนหน้า → หารด้วยขนาดหน้าเพื่อได้หน้าเต็ม → ใช้เศษสำหรับส่วนสุดท้าย → พิมพ์ทั้งสอง. การหารให้หน้าเต็ม และเศษให้ส่วนที่เหลือ
**โจทย์**
- **แบ่งเวลา** — เขียนโปรแกรมที่มี int s = 135 และพิมพ์นาทีเป็น s / 60 และวินาทีเป็น s % 60 โดยมีคำว่า min และ sec นำหน้า. ผลลัพธ์ที่ได้: `min 2 sec 15`. คำใบ้: ใช้ jout กับคำ ค่า และช่องว่าง

## ตัวดำเนินการบิต: & | xor << >>
**คืออะไร.** ตัวดำเนินการบิตทำกับบิตของจำนวนเต็ม & เก็บบิตที่สองข้างมีร่วมกัน | ใส่บิตถ้าข้างใดข้างหนึ่งมี xor ซึ่งเขียนเป็นคำ พลิกบิตตรงที่สองข้างต่างกัน << เลื่อนบิตไปทางซ้าย ซึ่งคูณสองทุกขั้น >> เลื่อนไปทางขวา ซึ่งหารสอง
**ทำไมต้องรู้.** แฟลก มาสก์ สี และการคำนวณเร็วใช้บิตเหล่านี้ การเขียน xor เป็นคำเป็นกฎของ J2K เพราะเครื่องหมาย ^ ใช้กับตัวชี้
**ทำอย่างไร.**

เขียนตัวดำเนินการระหว่างสองค่า ตัวอย่างใช้ 6 แสดงทุกตัวดำเนินการ 6 เป็น 110 ในไบนารี ดังนั้น 6 & 3 ได้ 010 ซึ่งคือ 2
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int x = 6;
    jout << (x & 3) << " " << (x | 1) << " " << (x xor 5) << " " << (x << 2) << " " << (x >> 1) << "\n";
}
```

```
2 7 3 24 3
```

> **ระวัง:** ตัวดำเนินการบิตผูกแน่นกว่าการเปรียบเทียบ ดังนั้น a & 1 == 0 หมายถึง (a & 1) == 0 ใส่วงเล็บเมื่อไม่แน่ใจ
**แบบฝึกหัด**
- 6 & 3 เท่ากับเท่าไร
  - a) 7  b) 2  c) 3  — เฉลย: b. 110 กับ 011 มีร่วมกันเพียงบิตค่า 2 คำตอบคือ 2
- x << 1 ทำอะไรกับจำนวนเต็ม
  - a) หารสอง  b) คูณสอง  c) บวกหนึ่ง  — เฉลย: b. การเลื่อนบิตไปทางซ้ายหนึ่งขั้นทำให้เลขเพิ่มเป็นสองเท่า
- xor เขียนด้วยเครื่องหมาย ^ ใน J2K — เฉลย: f. ^ หมายถึงตัวชี้ใน J2K จึงเขียน xor เป็นคำ
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int y = 8;
jout << (y >> 2) << "\n";
}
```
  ผลลัพธ์ที่ได้: `2`. เลื่อนบิตของ 8 ไปขวาสองตำแหน่งได้ 2
- คำที่พลิกบิตตรงที่สองค่าต่างกันคือ ___ — เฉลย: **xor**. xor พลิกบิตเมื่อสองข้างต่างกัน
- มาสก์บิตต่ำสองบิต: เขียนค่า → เขียน & 3 เพื่อเก็บบิตต่ำสอง → อ่านผล → พิมพ์. มาสก์เก็บเฉพาะบิตที่เลข 3 มี
**โจทย์**
- **บิตเป็นสองเท่า** — เขียนโปรแกรมที่มี int v = 5 และพิมพ์ v เลื่อนซ้ายหนึ่งบิต โดยมีคำว่า shifted นำหน้า. ผลลัพธ์ที่ได้: `shifted 10`. คำใบ้: ใช้ (v << 1) ใน jout

## อาร์เรย์: ขนาดและดัชนี
**คืออะไร.** อาร์เรย์เก็บจำนวนค่าคงที่ของชนิดเดียวกัน ประกาศด้วยขนาด เช่น int sizes[4] และแต่ละค่ามีดัชนีจาก 0 ถึงขนาดลบหนึ่ง sizes.len ให้ขนาด ลูปจึงเดินทั้งอาร์เรย์ได้
**ทำไมต้องรู้.** ลิสต์ตัวเลข คะแนน และพิกเซลเป็นอาร์เรย์ การอ่านดัชนีนอกช่วงเป็นบั๊ก และการตรวจในบิลด์ดีบักจะแสดงให้เห็น
**ทำอย่างไร.**

ประกาศอาร์เรย์พร้อมขนาดและค่าในวงเล็บปีกกาถ้ามี ใช้ for loop ที่ดัชนีจาก 0 ถึง sizes.len เพื่ออ่านแต่ละค่า ตัวอย่างบวกทุกค่าและพิมพ์ค่าสุดท้าย
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int sizes[4] = {2, 4, 6, 8};
    int sum = 0;
    for i in 0..sizes.len { sum += sizes[i]; }
    jout << "sum " << sum << " last " << sizes[3] << "\n";
}
```

```
sum 20 last 8
```

> **ระวัง:** ช่วง 0..sizes.len หยุดก่อนความยาว ดังนั้นดัชนีสุดท้ายคือ sizes.len ลบหนึ่ง ดัชนีที่เท่ากับความยาวอยู่นอกช่วง
**แบบฝึกหัด**
- int sizes[4] เก็บกี่ค่า
  - a) 3  b) 4  c) 5  — เฉลย: b. ขนาดในวงเล็บคือจำนวนค่า ในที่นี้คือ 4
- ดัชนีของค่าสุดท้ายใน int a[4] คืออะไร
  - a) 4  b) 3  c) 1  — เฉลย: b. ดัชนีวิ่งจาก 0 ถึง 3 ดังนั้นค่าสุดท้ายคือ 3
- ดัชนี 4 ใช้ได้ในอาร์เรย์ขนาด 4 — เฉลย: f. อาร์เรย์ขนาด 4 มีดัชนีที่ใช้ได้คือ 0, 1, 2 และ 3
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int a[3] = {1, 2, 3};
jout << a.len << "\n";
}
```
  ผลลัพธ์ที่ได้: `3`. a.len ให้ขนาดของอาร์เรย์ซึ่งคือ 3
- ฟิลด์ที่ให้ขนาดของอาร์เรย์คือ ___ — เฉลย: **len**. sizes.len ให้จำนวนค่าในอาร์เรย์
- รวมค่าในอาร์เรย์: ประกาศอาร์เรย์พร้อมค่า → ตั้งผลรวมเป็น 0 → วนดัชนี → บวกแต่ละค่าเข้าผลรวม. ผลรวมต้องเริ่มที่ศูนย์ก่อนลูปบวก
**โจทย์**
- **ผลรวมอาร์เรย์** — เขียนโปรแกรมที่มี int a[3] = {4, 5, 6} และพิมพ์คำว่า total ตามด้วยผลรวม. ผลลัพธ์ที่ได้: `total 15`. คำใบ้: ใช้ for loop กับ a.len หรือบวกทั้งสามดัชนีใน jout

## struct: กลุ่มค่ากับเมธอด
**คืออะไร.** struct รวมหลายค่าไว้ใต้ชื่อเดียว เช่น x และ y เมธอดคือฟังก์ชันภายใน struct ที่รับค่านั้นเป็น self เรียกด้วยจุด เช่น p.sum() ค่าของ struct เขียนด้วยวงเล็บปีกกาตามลำดับของฟิลด์
**ทำไมต้องรู้.** จุด สี่เหลี่ยม หรือผู้เล่นมีมากกว่าหนึ่งตัวเลข struct เก็บส่วนต่างๆ ไว้ด้วยกันจึงส่งต่อเป็นค่าเดียว
**ทำอย่างไร.**

ประกาศฟิลด์พร้อมชนิด เขียนเมธอดที่อ่าน self.x และ self.y สร้างค่าด้วยวงเล็บปีกกา แล้วเรียกเมธอดด้วยจุด ตัวอย่างมี struct หนึ่งตัวกับเมธอดที่บวกสองฟิลด์
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

struct Point {
    int x;
    int y;

    int sum(self) {
        return self.x + self.y;
    }
}

void main() {
    Point p = {3, 4};
    jout << p.sum() << "\n";
}
```

```
7
```

> **ระวัง:** เมธอดที่เปลี่ยนฟิลด์ต้องรับ self เป็นพารามิเตอร์แรก ไม่เช่นนั้นจะเปลี่ยนค่าที่มันเป็นเจ้าของไม่ได้
**แบบฝึกหัด**
- self อ้างถึงอะไรในเมธอด
  - a) โปรแกรม  b) ค่า struct ที่ถูกเรียกใช้เมธอด  c) ฟังก์ชัน main  — เฉลย: b. self คือค่าที่เมธอดถูกเรียก จึงอ่าน x ของมันด้วย self.x ได้
- โค้ดใดสร้าง Point ที่ x เป็น 1 และ y เป็น 2
  - a) Point p = {1, 2};  b) Point p = (1, 2);  c) p = Point;  — เฉลย: a. ค่า struct เขียนในวงเล็บปีกกาตามลำดับของฟิลด์
- struct รวมค่าที่เกี่ยวข้องกันไว้ใต้ชื่อเดียว — เฉลย: t. struct คือกลุ่มของฟิลด์ที่มีชื่อ เช่น x และ y ที่เก็บเป็นค่าเดียว
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

struct Box {
int w;
int h;
int area(self) {
    return self.w * self.h;
}
}

void main() {
Box b = {2, 5};
jout << b.area() << "\n";
}
```
  ผลลัพธ์ที่ได้: `10`. เมธอดคูณ w กับ h คือ 2 คูณ 5 ได้ 10
- ในเมธอด ชื่อที่ใช้เรียกค่าที่ถูกเรียกใช้คือ ___ — เฉลย: **self**. self คือพารามิเตอร์แรกของเมธอดและให้เข้าถึงฟิลด์
- ใช้ struct กับเมธอด: ประกาศฟิลด์ → เขียนเมธอดด้วย self → สร้างค่าด้วยวงเล็บปีกกา → เรียกเมธอดด้วยจุด. ต้องประกาศ struct ก่อนจึงสร้างค่าได้
**โจทย์**
- **พื้นที่** — เขียน struct Rect ที่มี int w และ int h และเมธอดที่คืนพื้นที่ สร้าง Rect r = {3, 3} แล้วพิมพ์พื้นที่. ผลลัพธ์ที่ได้: `9`. คำใบ้: ทำตามแบบ Point โดยใช้ self.w * self.h ในเมธอด

## enum class และ switch
**คืออะไร.** enum class คือชุดชื่อ เช่น Red, Yellow และ Green enum ไม่ใช่ตัวเลข คุณจึงบวกสองค่าไม่ได้ switch เลือกบล็อกตามค่า แต่ละกรณีเขียนด้วยชื่อ enum เช่น Light::Red ถ้าสมาชิกไม่มีกรณี คอมไพเลอร์จะเตือน
**ทำไมต้องรู้.** สถานะของไฟฟ้าจราจร เมนู หรือเกม ตั้งชื่อได้ดีกว่าเขียนเป็นตัวเลข และคอมไพเลอร์ตรวจว่ากรณีตรงกับชื่อ
**ทำอย่างไร.**

ประกาศ enum พร้อมชื่อ เขียนฟังก์ชันที่รับ enum และใช้ switch โดยมีหนึ่งกรณีต่อชื่อ ตัวอย่างพิมพ์ข้อความของแต่ละสัญญาณ
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

enum class Way { North, South };

void show(Way d) {
    switch d {
        Way::North: jout << "up\n";
        Way::South: jout << "down\n";
    }
}

void main() {
    show(Way::South);
}
```

```
down
```

> **ระวัง:** อย่าเปรียบเทียบ enum กับตัวเลข Way::North ไม่ใช่ 0 และคอมไพเลอร์ไม่ยอมให้ผสม
**แบบฝึกหัด**
- ใน J2K บวกค่า enum สองค่าได้ไหม
  - a) ได้เสมอ  b) ไม่ได้ เพราะ enum ไม่ใช่ตัวเลข  c) ได้เฉพาะใน struct  — เฉลย: b. enum คือชุดชื่อ ไม่ใช่ตัวเลข จึงคำนวณไม่ได้
- กรณีของ enum เขียนอย่างไร
  - a) North:  b) Way::North:  c) 0:  — เฉลย: b. กรณีระบุ enum และสมาชิกด้วย ::
- switch ที่ไม่มีกรณีครบทุกสมาชิกของ enum จะมีคำเตือน — เฉลย: t. คอมไพเลอร์เตือนเมื่อขาดสมาชิก เพื่อไม่ให้ลืมสถานะ
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

enum class Light { Red, Green };

void main() {
Light l = Light::Green;
switch l {
    Light::Red: jout << "stop\n";
    Light::Green: jout << "go\n";
}
}
```
  ผลลัพธ์ที่ได้: `go`. ค่าเป็น Green กรณีของ Green ทำงานและพิมพ์ go
- คีย์เวิร์ดที่ประกาศชุดชื่อคือ enum ___ — เฉลย: **class**. enum class Way ประกาศชุดชื่อ Way
- เลือกบล็อกด้วย enum: ประกาศ enum พร้อมชื่อ → เขียน switch ที่มีกรณีต่อชื่อ → เรียกฟังก์ชันด้วยสมาชิก → อ่านบรรทัดที่พิมพ์. enum ต้องมาก่อนเพื่อให้กรณีมีชื่อให้ตรง
**โจทย์**
- **สัญญาณ** — เขียน enum class Sig ที่มี Stop และ Go ฟังก์ชันที่พิมพ์ stop สำหรับ Stop และ go สำหรับ Go แล้วเรียกด้วย Sig::Go. ผลลัพธ์ที่ได้: `go`. คำใบ้: ใช้ switch เดียวที่มีกรณีต่อชื่อ

## ค่าคงที่ด้วย #define
**คืออะไร.** #define ตั้งชื่อให้ค่า คอมไพเลอร์แทนชื่อด้วยค่านั้นในข้อความก่อนสร้างโปรแกรม ชื่อมักเขียนด้วยตัวพิมพ์ใหญ่ เช่น MAX และวาง #define หลัง import และก่อนโค้ดที่ใช้
**ทำไมต้องรู้.** ขีดจำกัดหรือขนาดที่ใช้หลายที่ควรมีชื่อเดียว การเปลี่ยนจึงทำที่บรรทัดเดียว ไม่ใช่หลายบรรทัด
**ทำอย่างไร.**

เขียน #define NAME ค่า หลัง import และก่อน main แล้วใช้ชื่อตรงที่ต้องการค่า ตัวอย่างบวกเลข 0 ถึง 4 โดยใช้ MAX เป็นปลายช่วง
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

#define MAX 5

void main() {
    int total = 0;
    for i in 0..MAX { total += i; }
    jout << total << "\n";
}
```

```
10
```

> **ระวัง:** #define คือการแทนที่ข้อความ ไม่ใช่ตัวแปร คุณเอาที่อยู่ของมันหรือเปลี่ยนค่าไม่ได้ ถ้าค่าต้องเปลี่ยนให้ใช้ int
**แบบฝึกหัด**
- #define MAX 5 ทำอะไร
  - a) สร้างตัวแปรที่เปลี่ยนได้  b) แทนชื่อ MAX ด้วย 5 ในข้อความ  c) พิมพ์ 5  — เฉลย: b. #define แทนชื่อด้วยค่าก่อนการสร้าง
- ควรวาง #define ที่ไหน
  - a) หลัง main  b) ก่อนโค้ดที่ใช้  c) ท้ายไฟล์  — เฉลย: b. ต้องนิยามชื่อก่อนใช้ จึงวางก่อนโค้ด
- ค่าของ #define เปลี่ยนได้ภายหลังในโปรแกรม — เฉลย: f. #define ไม่ใช่ตัวแปร ค่าจึงคงเดิม
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

#define N 3

void main() {
jout << N * 2 << "\n";
}
```
  ผลลัพธ์ที่ได้: `6`. N ถูกแทนด้วย 3 โปรแกรมจึงคำนวณ 3 คูณ 2
- คำที่เริ่มการแทนที่ค่าคงที่ของข้อความคือ #___ — เฉลย: **define**. #define ตั้งชื่อให้ค่าก่อนการสร้าง
- ใช้ขีดจำกัดหลายที่: เขียน #define LIMIT หลัง import → ใช้ LIMIT ในลูป → คอมไพล์ → เปลี่ยนบรรทัดเดียวเพื่อเปลี่ยนทั้งหมด. นิยามเดียวถูกเปลี่ยนที่เดียว และการสร้างใช้ทุกที่
**โจทย์**
- **ขีดจำกัด** — เขียนโปรแกรมที่มี #define LIM 4 และพิมพ์ผลรวมของเลข 0 ถึง LIM ลบหนึ่ง. ผลลัพธ์ที่ได้: `6`. คำใบ้: ใช้ for i in 0..LIM ในลูปที่มี total += i
