## ติดตั้งและไฟล์แรก
**คืออะไร.** ก่อนจะเขียนโปรแกรมได้ คุณต้องมีตัวคอมไพเลอร์ jcmp ก่อน มันเป็นโปรแกรมที่แปลไฟล์ข้อความ .jk ของคุณให้เป็นไฟล์โปรแกรมที่รันได้ ไฟล์ .jk คือไฟล์ข้อความธรรมดาที่คุณเขียนเอง จะใช้โปรแกรมแก้ข้อความอะไรก็ได้ แต่ต้องบันทึกเป็นข้อความธรรมดา
**ทำไมต้องรู้.** ทุกบทเรียนต่อไปจะวนรอบเดียวกันนี้ คือเขียนไฟล์ คอมไพล์ รัน แล้วอ่านผล ถ้าขั้นนี้ยังไม่ผ่าน คุณจะเห็นแต่ข้อความผิดพลาดและไม่รู้ว่าทำอะไรผิด
**ทำอย่างไร.**

ติดตั้งด้วยคำสั่งติดตั้งในไฟล์ README ของโปรเจกต์ (ใช้ curl หรือ wget ตามที่มีในเครื่อง) แล้วตรวจด้วยคำสั่ง jcmp -version
สร้างไฟล์ชื่อ hello.jk แล้วเขียนโค้ดด้านล่าง
```jk
#import <stdlib>
using stdlib;

void main() {
    jout << "Hello, J2K!\n";
} 
```
คอมไพล์ด้วย jcmp hello.jk -o hello แล้วรันด้วย ./hello ถ้าเห็นข้อความ Hello, J2K! ก็สำเร็จ
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    jout << "Hello, J2K!\n";
    jout << "Second line\n";
}
```

```
Hello, J2K!
Second line
```

> **ระวัง:** ถ้าพิมพ์ jcmp แล้วขึ้นว่า command not found แปลว่าโปรแกรมนี้ยังไม่อยู่ในเส้นทางของระบบ ไม่ได้แปลว่าโค้ดผิด ให้เรียกด้วยที่อยู่เต็มของไฟล์แทน
**แบบฝึกหัด**
- ไฟล์ .jk คืออะไร
  - a) ไฟล์ข้อความที่มีโค้ดภาษา J2K  b) โปรแกรมที่รันได้แล้ว  c) รูปภาพของโค้ด  — เฉลย: a. ไฟล์ .jk เป็นข้อความธรรมดาที่คนอ่านได้ ตัวคอมไพเลอร์เป็นคนเปลี่ยนมันเป็นไฟล์โปรแกรม
- คุณต้องคอมไพล์ไฟล์ .jk ก่อนรันทุกครั้งที่แก้โค้ด — เฉลย: t. โปรแกรมที่รันคือผลจากการคอมไพล์ครั้งล่าสุดเท่านั้น ถ้าไม่คอมไพล์ใหม่ ผลที่เห็นคือโค้ดเก่า
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << "A\n";
jout << "B\n";
}
```
  ผลลัพธ์ที่ได้: `A / B`. โปรแกรมทำงานจากบนลงล่าง บรรทัดแรกพิมพ์ A แล้วขึ้นบรรทัดใหม่ ตามด้วย B
- ตัวเลือกที่ใช้ดูเวอร์ชันของ jcmp คือ -___ — เฉลย: **version**. ตัวเลือก -version บอกเวอร์ชันของคอมไพเลอร์ที่ติดตั้งอยู่
- ขั้นตอนของโปรแกรมแรก: สร้างไฟล์ hello.jk → คอมไพล์ด้วย jcmp → รันไฟล์ hello → อ่านผลที่พิมพ์ออกมา. ไฟล์ต้องมีอยู่ก่อนคอมไพล์ และต้องคอมไพล์สำเร็จก่อนรัน
- ทำไมต้องมีบรรทัด #import และ using ที่ด้านบน
  - a) เพื่อให้มีคำสั่ง jout และฟังก์ชันของไลบรารีมาตรฐาน  b) เพื่อให้โปรแกรมเร็วขึ้น  c) เพื่อบอกชื่อผู้เขียน  — เฉลย: a. ไลบรารี stdlib มี jout และฟังก์ชันพื้นฐาน ถ้าไม่ import โปรแกรมจะไม่รู้จักคำสั่งเหล่านั้น
**โจทย์**
- **ทักทาย** — เขียนโปรแกรมที่พิมพ์ข้อความ Hello, learner! หนึ่งบรรทัด. ผลลัพธ์ที่ได้: `Hello, learner!`. คำใบ้: ใช้ jout กับข้อความในเครื่องหมายคำพูดคู่ และอย่าลืม \n
- **สองบรรทัด** — เขียนโปรแกรมที่พิมพ์ one แล้วขึ้นบรรทัดใหม่ แล้วพิมพ์ two. ผลลัพธ์ที่ได้: `one / two`. คำใบ้: แต่ละบรรทัดใช้ jout หนึ่งคำสั่ง

## main และ jout
**คืออะไร.** main คือฟังก์ชันจุดเริ่มต้น โปรแกรมทุกตัวจะเริ่มทำงานที่ main และทำคำสั่งทีละบรรทัดจนถึงปีกกาปิด jout << คือคำสั่งพิมพ์ออกหน้าจอ มันรับข้อมูลได้หลายส่วนโดยต่อด้วย << ข้อความอยู่ในเครื่องหมายคำพูดคู่ เลขพิมพ์ตามตัวมันเอง และ \n คือการขึ้นบรรทัดใหม่
**ทำไมต้องรู้.** ทุกโปรแกรมที่คุณเห็นมี main เสมอ ถ้าขาด main คอมไพเลอร์จะไม่รู้ว่าจะเริ่มตรงไหน การพิมพ์ออกมาเป็นวิธีแรกที่คุณจะเห็นว่าโค้ดทำอะไร
**ทำอย่างไร.**

เขียนคำสั่งภายในปีกกาของ main ทุกคำสั่งจบด้วยเซมิโคลอน ;
```jk
void main() {
    jout << "total " << 6 * 7 << "\n";
} 
```
คำนวณ 6 * 7 ในวงเล็บของ jout โดยไม่ต้องเก็บในตัวแปรก่อน
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    jout << "A number: " << 42 << "\n";
    jout << "Two numbers: " << 3 << " and " << 4 << "\n";
    jout << 10 + 5 * 2 << "\n";
}
```

```
A number: 42
Two numbers: 3 and 4
20
```

> **ระวัง:** บรรทัดที่มีเพียงตัวเลขหลัง jout เช่น jout << n; แล้วไม่มีข้อความตาม เครื่องนี้ขึ้นบรรทัดใหม่ให้ด้วยในการทดลอง อย่าพึ่งพาพฤติกรรมนี้ ให้เขียน << "\n" เอง
**แบบฝึกหัด**
- ข้อความใดบอกว่าโปรแกรมเริ่มทำงานที่ไหน
  - a) ฟังก์ชัน main  b) บรรทัดแรกของไฟล์เสมอ  c) คำสั่ง jout  — เฉลย: a. J2K เริ่มทำงานที่ main เสมอ บรรทัดแรกของไฟล์อาจเป็น #import ซึ่งไม่ใช่ตัวเริ่มโปรแกรม
- \n ใน jout คือการเว้นวรรคหนึ่งช่อง — เฉลย: f. \n คือตัวอักษรขึ้นบรรทัดใหม่ ไม่ใช่ช่องว่าง ถ้าต้องการช่องว่างต้องเขียนเป็นข้อความที่มีเว้นวรรค
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << "x=" << 2 + 3 << "\n";
}
```
  ผลลัพธ์ที่ได้: `x=5`. เมื่อต่อด้วย << ค่า 2 + 3 ถูกคำนวณก่อนแล้วพิมพ์ติดกับ x= ทันที
- ทุกโปรแกรมเริ่มทำงานที่ฟังก์ชันชื่อ ___ — เฉลย: **main**. main คือชื่อจุดเริ่มต้นที่คอมไพเลอร์ค้นหา
- การพิมพ์ข้อความสองบรรทัดจากหนึ่งโปรแกรม: เขียนในปีกกาของ main → เรียก jout ครั้งแรกพร้อม \n → เรียก jout ครั้งที่สองพร้อม \n → รันเพื่อดูผลลัพธ์. คำสั่งทำงานตามลำดับบรรทัด และ \n ต้องอยู่ในแต่ละบรรทัดที่อยากขึ้นใหม่
- บรรทัดใดหายไปถ้าลืมเซมิโคลอนท้าย jout
  - a) คอมไพเลอร์ฟ้องว่าคำสั่งยังไม่จบ  b) ไม่มีอะไรหาย  c) โปรแกรมพิมพ์ซ้ำ  — เฉลย: a. เซมิโคลอนบอกจุดจบของคำสั่ง ถ้าไม่มี คอมไพเลอร์จะไม่รู้ว่าคำสั่งนี้จบที่ไหน
**โจทย์**
- **ตัวเลขและข้อความ** — เขียนโปรแกรมที่พิมพ์ข้อความ total 42 ในบรรทัดเดียว โดยคำนวณ 6 * 7 ใน jout. ผลลัพธ์ที่ได้: `total 42`. คำใบ้: ต่อข้อความ total กับตัวเลข 6 * 7 ด้วย <<
- **สามบรรทัด** — เขียนโปรแกรมที่พิมพ์ a แล้ว b แล้ว c บรรทัดละหนึ่งบรรทัด. ผลลัพธ์ที่ได้: `a / b / c`. คำใบ้: ใช้ jout สามครั้ง ที่ท้ายแต่ละครั้งมี \n

## ตัวแปรและชนิดข้อมูล
**คืออะไร.** ตัวแปรคือกล่องที่มีชื่อ เก็บค่าหนึ่งค่า และต้องประกาศชนิดของค่านั้น int เก็บจำนวนเต็ม double เก็บทศนิยม bool เก็บ true หรือ false char เก็บตัวอักษรหนึ่งตัวในเครื่องหมายคำพูดเดี่ยว และ String เก็บข้อความในเครื่องหมายคำพูดคู่ ชนิดคือสิ่งที่บอกว่าค่านั้นทำอะไรได้บ้าง
**ทำไมต้องรู้.** ถ้าคุณเก็บตัวเลขในข้อความ คุณจะบวกมันไม่ได้ ถ้าเก็บทศนิยมใน int คุณจะเสียส่วนทศนิยมไปเงียบ ๆ การเลือกชนิดให้ถูกทำให้โปรแกรมปลอดภัยและคอมไพเลอร์ช่วยตรวจได้
**ทำอย่างไร.**

ประกาศด้วยชนิด ชื่อ = ค่า; เช่น int apples = 5; และเปลี่ยนค่าด้วย = โดยไม่ต้องเขียนชนิดซ้ำ
```jk
int apples = 5;
apples = apples + 2;
double price = 2.5;
String name = "Ann";
```
ค่า int และ double ต่างชนิดกัน ถ้าจะผสมต้องแปลงด้วยวงเล็บชนิด เช่น (double)apples
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int apples = 5;
    apples = apples + 2;
    double price = 2.5;
    bool sunny = true;
    char letter = 'J';
    String name = "Ann";
    jout << apples << " " << price << " " << sunny << "\n";
    jout << letter << name << "\n";
    int half = (int)(price * 2.0);
    jout << half << "\n";
}
```

```
7 2.500000 true
JAnn
5
```

> **ระวัง:** จำนวนเต็มหารกันจะตัดทศนิยมทิ้ง 7 / 2 ได้ 3 ถ้าต้องการทศนิยมให้ใช้ 7.0 / 2.0 และเช็กว่าชนิดของทั้งสองข้างเหมือนกัน
**แบบฝึกหัด**
- ชนิดใดเหมาะกับตัวอักษรหนึ่งตัว
  - a) char  b) String  c) bool  — เฉลย: a. char เก็บตัวอักษรหนึ่งตัวในเครื่องหมายคำพูดเดี่ยว ส่วน String เก็บข้อความที่ยาวกว่านั้น
- int x = 2.5; เป็นโค้ดที่ถูกต้อง — เฉลย: f. 2.5 เป็นทศนิยม แต่ int เก็บเฉพาะจำนวนเต็ม ต้องใช้ double หรือเปลี่ยนให้เป็นจำนวนเต็มก่อน
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int a = 7;
int b = 2;
jout << a / b << "\n";
}
```
  ผลลัพธ์ที่ได้: `3`. ทั้งสองค่าเป็น int จึงเป็นการหารจำนวนเต็ม ได้ 3 ส่วนทศนิยมถูกตัดทิ้ง
- ตัวแปรที่เก็บค่าจริงเป็นทศนิยมคือชนิด ___ — เฉลย: **double**. double เก็บทศนิยม ส่วน int เก็บเฉพาะจำนวนเต็ม
- การใช้ตัวแปรหนึ่งตัว: ประกาศชนิดและชื่อ → ให้ค่าเริ่มต้น → เปลี่ยนค่าถ้าต้องการ → ใช้ค่านั้นใน jout. ต้องประกาศก่อนใช้ และให้ค่าก่อนอ่านค่า
- ทำไม if total ที่ total เป็น int จึงผิด
  - a) เงื่อนไขต้องเป็น bool  b) เพราะ total เป็นตัวเลข  c) ไม่ผิด  — เฉลย: a. if ต้องการค่า true หรือ false ถ้าเป็นตัวเลข ต้องเขียนเปรียบเทียบ เช่น total != 0
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
double d = 3.0;
jout << (int)d << "\n";
}
```
  ผลลัพธ์ที่ได้: `3`. การแปลง (int) ตัดส่วนทศนิยมออกจากค่า 3.0 ได้ 3
**โจทย์**
- **หารและเศษ** — เก็บ 7 และ 2 ใน int แล้วพิมพ์ผลหารและเศษ ในรูป 3 1. ผลลัพธ์ที่ได้: `3 1`. คำใบ้: ใช้ / สำหรับผลหาร และ % สำหรับเศษ
- **ยอดรวม** — ราคา double 2.5 จำนวน 4 ชิ้น พิมพ์ข้อความ total ตามด้วยยอดรวมเป็นทศนิยม. ผลลัพธ์ที่ได้: `total 10.000000`. คำใบ้: jout แสดงทศนิยมแบบหกตำแหน่ง ใช้ double ทั้งสองค่า
- **ชื่อ** — เก็บ J2K ใน String name แล้วพิมพ์ name ตามด้วย rocks. ผลลัพธ์ที่ได้: `J2K rocks`. คำใบ้: ใช้ + เพื่อต่อข้อความ โดยมีช่องว่างในข้อความ

## คำนวณและเปรียบเทียบ
**คืออะไร.** ตัวดำเนินการคำนวณคือ + - * / และ % (เศษ) เรียงลำดับความสำคัญคูณหารก่อนบวกลบ ใช้วงเล็บเปลี่ยนลำดับได้ การเปรียบเทียบ == != < > <= >= ได้ผลเป็น bool ส่วนการรวมเงื่อนไขใช้ && (และ) และ ! (ไม่)
**ทำไมต้องรู้.** เกือบทุกโปรแกรมต้องตัดสินใจจากตัวเลข เช่น ราคาพอหรือไม่ เกินขีดจำกัดหรือยัง การเข้าใจลำดับและผลเปรียบเทียบทำให้เงื่อนไขของคุณตรงกับที่คิด
**ทำอย่างไร.**

เขียนสูตรทีละขั้น ถ้าไม่แน่ใจให้ใส่วงเล็บ เพื่อให้คนอ่านและคอมไพเลอร์เข้าใจตรงกัน
```jk
int a = 7;
int b = 2;
jout << (a + b) * 3 << "\n";
jout << (a >= 3 && b < 1) << "\n";
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int a = 7;
    int b = 2;
    jout << 2 + 3 * 4 << "\n";
    jout << (2 + 3) * 4 << "\n";
    jout << a % b << "\n";
    jout << (a >= 3 && b < 1) << "\n";
    jout << !(a == 7) << "\n";
}
```

```
14
20
1
false
false
```

> **ระวัง:** เขียน a & b == 0 ไม่ได้หมายความว่าตามที่คิด ใช้วงเล็บเสมอเมื่อผสมตัวดำเนินการหลายชนิด และอย่าสับสนระหว่าง = กับ ==
**แบบฝึกหัด**
- ผลของ 2 + 3 * 4 เท่ากับเท่าใด
  - a) 14  b) 20  c) 24  — เฉลย: a. การคูณทำก่อน จึงได้ 3 * 4 เท่ากับ 12 แล้วบวก 2

## เงื่อนไข if
**คืออะไร.** if ทำบล็อกคำสั่งเมื่อเงื่อนไขเป็น true else if ลองเงื่อนไขอื่นถ้าอันแรกไม่จริง และ else ทำเมื่อไม่มีอันใดจริงเลย ปีกกาต้องมีเสมอ เงื่อนไขต้องเป็น bool และ if ซ้อนกันได้เมื่อต้องตรวจหลายชั้น
**ทำไมต้องรู้.** โปรแกรมเกือบทุกโปรแกรมมีการเลือกทาง เช่น ซื้อได้หรือไม่ ผ่านหรือไม่ การเขียน if ที่ตรงกับความคิดของคุณคือทักษะหลัก และถ้าเรียงลำดับเงื่อนไขผิด ผลจะผิดโดยไม่มีข้อความเตือน
**ทำอย่างไร.**

เขียนเงื่อนไขที่แคบที่สุดก่อน เพราะเมื่อ else if อันแรกจริงแล้วอันอื่นจะไม่ถูกตรวจ
```jk
int score = 72;
if score >= 90 {
    jout << "A\n";
} else if score >= 70 {
    jout << "B\n";
} else {
    jout << "C\n";
}
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int score = 72;
    if score >= 90 {
        jout << "A\n";
    } else if score >= 70 {
        jout << "B\n";
    } else {
        jout << "C\n";
    }
    bool passed = score >= 50;
    if passed { jout << "passed\n"; }
    if score >= 50 {
        if score >= 70 { jout << "good pass\n"; }
    }
}
```

```
B
passed
good pass
```

> **ระวัง:** เขียน if n { โดย n เป็น int จะขึ้นข้อความว่าต้องการ bool เขียนเป็น if n != 0 แทน และอย่าลืมเครื่องหมายปีกกาหลัง if เสมอ
**แบบฝึกหัด**
- ถ้า score เป็น 95 ผลแรกจะพิมพ์อะไร
  - a) A  b) B  c) C  — เฉลย: a. 95 มากกว่า 90 ซึ่งเป็นเงื่อนไขแรก เมื่อจริงแล้ว บล็อกนั้นทำ และเงื่อนไขอื่นไม่ถูกตรวจ
- else จำเป็นต้องมีเสมอหลัง if — เฉลย: f. else เป็นทางเลือกเมื่อไม่มีเงื่อนไขใดจริง โปรแกรมจะข้ามได้ถ้าไม่ต้องการทำอะไรอีก
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int n = -4;
if n > 0 {
    jout << "positive\n";
} else if n < 0 {
    jout << "negative\n";
} else {
    jout << "zero\n";
}
}
```
  ผลลัพธ์ที่ได้: `negative`. -4 ไม่มากกว่า 0 จึงไปเช็กเงื่อนไขที่สอง และ -4 น้อยกว่า 0
- คำที่ใช้ทำบล็อกเมื่อเงื่อนไขทั้งหมดไม่จริงคือ ___ — เฉลย: **else**. else เป็นทางสุดท้ายที่ทำเมื่อเงื่อนไขก่อนหน้าไม่จริงทั้งหมด
- ลำดับการทำงานของ if ที่มี else if: ตรวจ if ก่อน → ถ้าไม่จริงตรวจ else if → ถ้ายังไม่จริงทำ else → จบ. เงื่อนไขถูกตรวจตามลำดับ และทำเพียงบล็อกเดียว
- ทำไมต้องเรียงจาก >= 90 ก่อน >= 70
  - a) เพราะอันแรกที่จริงจะถูกทำ ถ้าเรียงกลับ 95 จะได้ B  b) เพราะตัวเลขต้องเรียง  c) ไม่สำคัญ  — เฉลย: a. ถ้าเรียง >= 70 ก่อน ทุกคะแนนตั้งแต่ 70 จะได้ B หมด
- ทายผลลัพธ์ของโค้ด:


**โจทย์**
- **ผ่านไม่ผ่าน** — ถ้าคะแนน 60 มากกว่าหรือเท่ากับ 50 พิมพ์ pass ไม่เช่นนั้นพิมพ์ fail. ผลลัพธ์ที่ได้: `pass`. คำใบ้: ใช้ if และ else
- **เครื่องหมายของจำนวน** — เก็บ -4 ใน n แล้วพิมพ์ positive zero หรือ negative ตามค่า n. ผลลัพธ์ที่ได้: `negative`. คำใบ้: ใช้ else if สองทาง
- **FizzBuzz** — วนตั้งแต่ 1 ถึง 15 พิมพ์ตัวเลข ถ้าหารด้วย 3 ลงตัวพิมพ์ Fizz ถ้าหารด้วย 5 ลงตัวพิมพ์ Buzz ถ้าลงตัวทั้งคู่พิมพ์ FizzBuzz. ผลลัพธ์ที่ได้: `1 / 2 / Fizz / 4 / Buzz / Fizz / 7 / 8 / Fizz / Buzz / 11 / Fizz / 13 / 14 / FizzBuzz`. คำใบ้: ตรวจว่าหารลงตัวทั้งสองก่อนแล้วจึงตรวจทีละตัว

## ลูป
**คืออะไร.** ลูป while ทำซ้ำตราบที่เงื่อนไขเป็น true ลูป for i in a..b นับ i จาก a ถึง b - 1 และมี for แบบ C ที่ประกาศตัวนับ เงื่อนไข และการเพิ่มค่าในบรรทัดเดียว break ออกจากลูปทันที continue ข้ามไปรอบถัดไป
**ทำไมต้องรู้.** งานที่ต้องทำซ้ำหลายครั้ง เช่นบวกหนึ่งร้อยตัว ค้นหาในรายการ หรือทำจนได้ค่าที่พอใจ ถ้าต้องเขียนทีละบรรทัดจะยาวและพลาดง่าย ลูปแก้ปัญหาเหล่านี้
**ทำอย่างไร.**

เลือกลูปตามความรู้ของคุณ ถ้ารู้จำนวนรอบแน่นอนใช้ for ถ้ายังไม่รู้จำนวนรอบใช้ while
```jk
int sum = 0;
for k in 1..11 { sum += k; }
jout << sum << "\n";
int i = 1;
while i <= 3 { i++; }
jout << i << "\n";
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int i = 1;
    while i <= 3 {
        jout << i << " ";
        i++;
    }
    jout << "\n";
    for k in 0..5 { jout << k * k << " "; }
    jout << "\n";
    for int j = 10; j > 0; j -= 3 { jout << j << " "; }
    jout << "\n";
}
```

```
1 2 3 
0 1 4 9 16 
10 7 4 1
```

> **ระวัง:** for i in 1..4 ไม่รวม 4 ถ้าอยากให้ 4 อยู่ในลูปต้องเขียน 1..5 และระวัง while ที่ไม่มีการเปลี่ยนค่า จะวนไปตลอด
**แบบฝึกหัด**
- for i in 0..3 วนกี่รอบ
  - a) 3  b) 4  c) 2  — เฉลย: a. 0..3 หมายถึง 0 1 2 ไม่รวม 3 จึงได้สามรอบ
- break ทำให้โปรแกรมหยุดทั้งหมด — เฉลย: f. break ออกจากลูปที่อยู่ล่าสุดเท่านั้น โปรแกรมทำคำสั่งต่อไปหลังลูปได้
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
for i in 0..5 {
    if i == 2 { continue; }
    jout << i << "\n";
}
}
```
  ผลลัพธ์ที่ได้: `0 / 1 / 3 / 4`. continue ข้ามการพิมพ์เมื่อ i เป็น 2 แล้วไปรอบถัดไป
- คำสั่งที่ออกจากลูปทันทีคือ ___ — เฉลย: **break**. break ใช้เมื่อพบสิ่งที่ต้องการแล้วไม่ต้องวนต่อ
- การนับผลรวมของ 1 ถึง 10 ด้วย for: ประกาศ sum เป็น 0 → วนด้วย for k in 1..11 → บวก k เข้า sum → พิมพ์ sum. ค่า sum ต้องมีก่อนบวก และการบวกต้องอยู่ในลูป
- ทำไมลูป while ที่ไม่เปลี่ยนค่าอาจไม่จบ
  - a) เพราะเงื่อนไขยังเป็น true ตลอด  b) เพราะ jout ช้า  c) เพราะต้องใช้ break ทุกครั้ง  — เฉลย: a. ถ้าเงื่อนไขไม่เปลี่ยนเป็น false ลูปจะวนต่อไปไม่สิ้นสุด
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int n = 6;
int steps = 0;
while n != 1 {
    if n % 2 == 0 { n = n / 2; } else { n = n * 3 + 1; }
    steps += 1;
}
jout << steps << "\n";
}
```
  ผลลัพธ์ที่ได้: `8`. 6 ไป 3 ไป 10 ไป 5 ไป 16 ไป 8 ไป 4 ไป 2 ไป 1 รวมแปดขั้น
**โจทย์**
- **ผลรวมหนึ่งถึงสิบ** — ใช้ for รวมเลข 1 ถึง 10 แล้วพิมพ์ข้อความ sum ตามด้วยผลรวม. ผลลัพธ์ที่ได้: `sum 55`. คำใบ้: ใช้ for k in 1..11
- **นับถอยหลัง** — พิมพ์เลข 10 ลงมาถึง 1 โดยลดทีละ 3 บรรทัดละหนึ่งค่า. ผลลัพธ์ที่ได้: `10 / 7 / 4 / 1`. คำใบ้: ใช้ for int j = 10; j > 0; j -= 3
- **ทำซ้ำจนพบ** — เริ่มที่ 6 ทำตามกติกา collatz คือถ้าคู่หารสอง ถ้าคี่คูณสามบวกหนึ่ง ทำจนได้ 1 แล้วพิมพ์ steps ตามด้วยจำนวนรอบ. ผลลัพธ์ที่ได้: `steps 8`. คำใบ้: ใช้ while n != 1 และนับทีละหนึ่ง

## ลูปซ้อน
**คืออะไร.** ลูปอยู่ในลูปได้ ลูปด้านในทำครบทุกรอบก่อนลูปด้านนอกจะขยับหนึ่งครั้ง จำนวนครั้งทั้งหมดเท่ากับผลคูณของจำนวนรอบของแต่ละลูป ลูปซ้อนใช้กับตาราง คู่ทั้งหมด และแถวกับคอลัมน์
**ทำไมต้องรู้.** ตารางข้อมูล ภาพ และกริดเกมเป็นลูปซ้อนทั้งหมด ถ้าคุณเข้าใจว่าลูปในทำงานกี่รอบต่อหนึ่งรอบของลูปนอก คุณจะคำนวณเวลาและผลได้ถูก
**ทำอย่างไร.**

ลูปนอกใช้ตัวแปรแถว r ลูปในใช้ตัวแปรคอลัมน์ c
```jk
for r in 1..4 {
    for c in 1..4 {
        jout << r * c << " ";
    }
    jout << "\n";
}
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    for r in 1..4 {
        for c in 1..4 { jout << r * c << " "; }
        jout << "\n";
    }
    for r in 1..4 {
        for c in 1..4 {
            if c <= r { jout << "*"; }
        }
        jout << "\n";
    }
}
```

```
1 2 3 
2 4 6 
3 6 9 
*
**
***
```

> **ระวัง:** ลูปใน for c in 1..4 ใช้ตัวแปรชื่อ c เดียวกับลูปนอกไม่ได้ เพราะชื่อจะชนกัน ให้ตั้งชื่อต่างกัน เช่น r และ c
**แบบฝึกหัด**
- ถ้าลูปนอกวน 3 รอบและลูปในวน 4 รอบ จะมีกี่ครั้งรวมกัน
  - a) 12  b) 7  c) 34  — เฉลย: a. 3 คูณ 4 เท่ากับ 12 เพราะทุกรอบของลูปนอกมีลูปในเต็มทั้งหมด
- ลูปในหยุดไม่ได้จนกว่าลูปนอกจะจบ — เฉลย: t. ลูปในต้องวนให้ครบก่อนที่ลูปนอกจะเดินหนึ่งรอบ นี่คือเหตุผลที่ลูปนอกใช้เวลามากขึ้นมาก
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int count = 0;
for i in 0..3 {
    for j in 0..2 { count += 1; }
}
jout << count << "\n";
}
```
  ผลลัพธ์ที่ได้: `6`. ลูปนอกสามรอบ ลูปในสองรอบ รวมหกครั้ง
- ลูปที่อยู่ภายในลูปอื่นเรียกว่าลูป ___ — เฉลย: **nested**. nested loop คือลูปซ้อนกัน
- การพิมพ์ตารางสามแถวด้วยลูปซ้อน: วนลูปนอกเพื่อเลือกแถว → วนลูปในเพื่อพิมพ์ทุกคอลัมน์ → ขึ้นบรรทัดใหม่หลังแต่ละแถว → พิมพ์ทั้งตาราง. แถวจะถูกเริ่มโดยลูปนอก และคอลัมน์ทั้งหมดถูกพิมพ์ในลูปใน
- ถ้าลืม \n หลังลูปใน ผลจะเป็นอย่างไร
  - a) ทุกค่าอยู่บรรทัดเดียว  b) โปรแกรมไม่คอมไพล์  c) ตารางกลับด้าน  — เฉลย: a. ไม่มีคำสั่งขึ้นบรรทัดใหม่ ค่าทั้งหมดจึงต่อกันบนบรรทัดเดียว
**โจทย์**
- **รูปสามเหลี่ยม** — พิมพ์ดาวสามบรรทัด บรรทัดแรกหนึ่งดวง บรรทัดที่สองสองดวง บรรทัดที่สามสามดวง. ผลลัพธ์ที่ได้: `* / ** / ***`. คำใบ้: ลูปใน วนตามเลขแถว
- **นับคู่** — นับคู่ (i, j) โดยที่ i อยู่ใน 1..4 และ j อยู่ใน 1..4 และ i น้อยกว่า j แล้วพิมพ์ pairs 6. ผลลัพธ์ที่ได้: `pairs 6`. คำใบ้: ใช้ if ในลูปใน
- **ตารางคูณ** — พิมพ์ตารางคูณ 1 ถึง 3 โดยคั่นด้วยช่องว่าง บรรทัดละแถว. ผลลัพธ์ที่ได้: `1 2 3 / 2 4 6 / 3 6 9`. คำใบ้: ดูตัวอย่างในหัวข้อนี้ และตรวจว่าไม่มีช่องว่างตอนท้ายแถว

## jin: รับค่าจากคีย์บอร์ด
**คืออะไร.** jin >> คือคำสั่งรับค่าจากคีย์บอร์ดหรือจากท่อข้อมูล มันอ่านทีละคำ คำแยกกันด้วยช่องว่างหรือขึ้นบรรทัดใหม่ ชนิดของตัวแปรเป็นตัวกำหนดว่าจะอ่านอะไร ตัวแปร int อ่านตัวเลข ตัวแปร char array อ่านข้อความ
**ทำไมต้องรู้.** โปรแกรมที่ทำงานเดียวกันทุกครั้งไม่มีประโยชน์มาก เมื่อโปรแกรมรับค่าจากคนได้ มันจะยืดหยุ่นขึ้น แต่ต้องรู้ว่าอินพุตที่มาผิดรูปแบบจะทำให้โปรแกรมหยุดพร้อมข้อความ
**ทำอย่างไร.**

ประกาศตัวแปรให้ตรงชนิด แล้วเขียน jin >> ชื่อ >> ชื่อ; ตามลำดับที่คนจะพิมพ์
```jk
char name[20];
int age;
```
ทดสอบด้วยการป้อนผ่านท่อข้อมูลได้ เช่น echo "Ann 30" | ./program
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    char name[20];
    int age;
    jin >> name >> age;
    jout << name << " will be " << age + 1 << " next year\n";
}
input: Ann 30
```

```
Ann will be 31 next year
```

> **ระวัง:** ถ้าอินพุตหมดก่อนจะถึงตัวเลข โปรแกรมจะหยุดพร้อมข้อความ end of input และถ้าพิมพ์คำแทนตัวเลขจะเป็น invalid input เสมอให้คิดว่าผู้ใช้อาจพิมพ์ผิด
**แบบฝึกหัด**
- jin ตัดสินใจชนิดของค่าที่อ่านจากอะไร
  - a) ชนิดของตัวแปรที่รับค่า  b) ลำดับที่พิมพ์  c) ชื่อของโปรแกรม  — เฉลย: a. ตัวแปร int จะอ่านเป็นตัวเลข ส่วน char array จะอ่านเป็นข้อความ
- jin อ่านได้ทั้งบรรทัดรวมช่องว่างเสมอ — เฉลย: f. jin แยกคำด้วยช่องว่างและขึ้นบรรทัด ถ้าอยากได้ทั้งบรรทัด ต้องใช้วิธีอ่านบรรทัดแบบอื่น
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int a = 4;
int b = 2;
jout << "in " << a + b << "\n";
}
```
  ผลลัพธ์ที่ได้: `in 6`. ไม่มี jin ในโค้ดนี้ ค่า a + b คือ 6 และพิมพ์ตามข้อความ
- คำสั่งรับค่าจากคีย์บอร์ดของ J2K คือ ___ — เฉลย: **jin**. jin >> บอกทิศทางที่ค่าไหลเข้าตัวแปร
- การรับชื่อและอายุจากผู้ใช้: ประกาศ char name[20] และ int age → เรียก jin >> name >> age → ใช้ค่าในการพิมพ์ → คอมไพล์และรัน. ตัวแปรต้องมีก่อนรับค่า และการรับค่าต้องเกิดก่อนการใช้
- ทำไมควรใส่ขนาดให้ char name[20]
  - a) เพื่อจองที่สำหรับตัวอักษรที่จะรับ  b) เพื่อให้พิมพ์ได้เร็วขึ้น  c) เพื่อให้ตัวเลขเป็นทศนิยม  — เฉลย: a. char array มีขนาดคงที่ ถ้าข้อความยาวเกินจะไม่พอที่เก็บ
**โจทย์**
- **ทักทาย** — ประกาศ char name[] เป็น "Ann" แล้วพิมพ์ hi Ann. ผลลัพธ์ที่ได้: `hi Ann`. คำใบ้: ใช้ char name[] = "Ann"; กับข้อความที่เขียนเป็น hi ตามด้วยชื่อ
- **ตัวเลขจากข้อความ** — เก็บข้อความ "30" ในตัวแปร String แล้วแปลงเป็นตัวเลข บวก 1 แล้วพิมพ์. ผลลัพธ์ที่ได้: `31`. คำใบ้: to_int แปลงข้อความเป็นจำนวนก่อนบวก

## ฟังก์ชัน
**คืออะไร.** ฟังก์ชันคือชุดคำสั่งที่มีชื่อ รับพารามิเตอร์เข้ามาและอาจคืนค่ากลับด้วย return ชนิดที่เขียนหน้าชื่อบอกชนิดของค่าที่คืน void หมายถึงไม่คืนค่า ฟังก์ชันเรียกตัวเองได้ (recursion) ถ้ามีเงื่อนไขหยุด และเรียงลำดับไว้ที่ไหนก็ได้ในไฟล์
**ทำไมต้องรู้.** ฟังก์ชันทำให้โค้ดไม่ซ้ำ อ่านง่ายขึ้น และทดสอบได้ทีละส่วน ทุกโปรแกรมใหญ่ประกอบจากฟังก์ชันเล็ก ๆ
**ทำอย่างไร.**

เขียนชนิด ชื่อ (พารามิเตอร์) แล้วใส่ return ค่า;
```jk
#import <stdlib>
using stdlib;

int square(int x) {
    return x * x;
}

void main() {
    jout << square(4) << "\n";
}
```
การส่งค่าเข้าฟังก์ชันจะคัดลอกค่าเข้าไป ดังนั้นการเปลี่ยนพารามิเตอร์ในฟังก์ชันไม่ทำให้ตัวแปรเดิมเปลี่ยน
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    jout << factorial(5) << "\n";
    jout << square(7) << "\n";
}

int factorial(int n) {
    if n <= 1 { return 1; }
    return n * factorial(n - 1);
}

int square(int x) {
    return x * x;
}
```

```
120
49
```

> **ระวัง:** ฟังก์ชันที่ต้องคืนค่าแต่ไม่มี return ตามเงื่อนไขทุกทาง จะถูกคอมไพเลอร์เตือนหรือให้ผลไม่แน่นอน และถ้าเรียกตัวเองโดยไม่มีจุดหยุด โปรแกรมจะไม่จบ
**แบบฝึกหัด**
- ฟังก์ชันที่ไม่คืนค่าควรประกาศชนิดใด
  - a) void  b) int  c) bool  — เฉลย: a. void บอกว่าไม่มีค่ากลับ
- การแก้ค่าพารามิเตอร์ในฟังก์ชันจะเปลี่ยนตัวแปรเดิมในฟังก์ชันที่เรียก — เฉลย: f. ค่าถูกคัดลอกเข้าไปให้ฟังก์ชัน ตัวแปรเดิมไม่เปลี่ยน ถ้าต้องการให้เปลี่ยนต้องใช้พอยน์เตอร์ซึ่งจะเรียนทีหลัง
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
jout << twice(4) << "\n";
}

int twice(int n) {
return n * 2;
}
```
  ผลลัพธ์ที่ได้: `8`. ฟังก์ชันรับ 4 เป็น n แล้วคืน 8 ไปให้ jout
- คำสั่งที่ส่งค่ากลับจากฟังก์ชันคือ ___ — เฉลย: **return**. return ส่งค่ากลับไปให้ผู้เรียกและจบฟังก์ชันทันที
- การเรียกฟังก์ชัน square ที่ส่ง 3: ส่ง 3 เป็นพารามิเตอร์ → คำนวณ x * x → return 9 → ผู้เรียกได้ค่า 9. ค่าต้องถูกส่งเข้าไปก่อน จึงคำนวณได้
- ฟังก์ชันเรียกตัวเองเพื่ออะไร
  - a) แบ่งงานใหญ่เป็นงานเล็กที่เหมือนเดิม  b) ทำให้ช้าลง  c) ลบตัวแปร  — เฉลย: a. recursion แบ่งปัญหาให้เล็กลงเรื่อย ๆ จนถึงกรณีพื้นฐาน
**โจทย์**
- **กำลังสอง** — เขียนฟังก์ชัน square แล้วพิมพ์ square(7). ผลลัพธ์ที่ได้: `49`. คำใบ้: ใช้ int square(int x) และ return x * x
- **แฟกทอเรียล** — เขียนฟังก์ชัน factorial แบบเรียกตัวเอง แล้วพิมพ์ factorial(5). ผลลัพธ์ที่ได้: `120`. คำใบ้: จุดหยุดคือ n น้อยกว่าหรือเท่ากับ 1 ให้คืน 1
- **ค่าสูงสุดสามค่า** — เขียนฟังก์ชัน max3(a, b, c) คืนค่าที่มากที่สุด แล้วพิมพ์ max3(4, 9, 2). ผลลัพธ์ที่ได้: `9`. คำใบ้: ใช้ if สองขั้นหรือเทียบทีละคู่

## อาเรย์
**คืออะไร.** อาเรย์คือค่าชนิดเดียวกันหลายค่าในตัวแปรเดียว ประกาศ int scores[5] ได้ห้าช่องนับจาก 0 scores.len คือความยาว อาเรย์ขนาดยืดได้คือ int[] list = arr(4) แล้วเพิ่มด้วย push ทั้งสองแบบเก็บข้อมูลติดกันในหน่วยความจำ
**ทำไมต้องรู้.** ข้อมูลส่วนใหญ่มาเป็นชุด เช่นคะแนนนักเรียน ราคาสินค้า หรือพิกเซลของภาพ อาเรย์เป็นวิธีเก็บชุดเหล่านี้ และเป็นพื้นฐานของทุกโครงสร้างข้อมูลที่จะเรียนต่อ
**ทำอย่างไร.**

ประกาศขนาด เติมค่าด้วยลูปหรือกำหนดทีละช่อง แล้วอ่านด้วยลูป for i in 0..len
```jk
int scores[5];
for i in 0..5 { scores[i] = (i + 1) * 10; }
int total = 0;
for i in 0..scores.len { total += scores[i]; }
jout << total << "\n";
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    int scores[5];
    for i in 0..5 { scores[i] = (i + 1) * 10; }
    int total = 0;
    for i in 0..scores.len { total += scores[i]; }
    jout << "total " << total << "\n";
    int grid[2][3];
    for r in 0..2 {
        for c in 0..3 { grid[r][c] = r * 3 + c; }
    }
    jout << grid[1][2] << "\n";
}
```

```
total 150
5
```

> **ระวัง:** อาเรย์มีช่องตั้งแต่ 0 ถึง len - 1 การเขียน scores[5] คือช่องที่หกซึ่งไม่มีอยู่ ใช้ -d ตอนคอมไพล์เพื่อให้ตรวจขอบตอนรัน
**แบบฝึกหัด**
- int scores[5] มีช่องกี่ช่อง
  - a) 5  b) 4  c) 6  — เฉลย: a. ตั้งแต่ 0 ถึง 4 รวมห้าช่อง
- arr(4) สร้างอาเรย์ที่มีสี่ค่าเริ่มต้นเป็นศูนย์ทันที — เฉลย: f. arr(4) เป็นอาเรย์ที่ยังว่างและจะยืดด้วย push ถ้าต้องการค่าเริ่มต้นต้องใส่ค่าเอง
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int a[3];
a[0] = 2; a[1] = 4; a[2] = 6;
jout << a[1] + a[2] << "\n";
}
```
  ผลลัพธ์ที่ได้: `10`. a[1] คือ 4 และ a[2] คือ 6 รวมเป็น 10
- จำนวนช่องของอาเรย์เขียนได้ด้วย .___ — เฉลย: **len**. .len คือความยาวของอาเรย์
- การหาค่ามากที่สุดในอาเรย์: ตั้ง best เป็นช่องแรก → วนจากช่องที่สอง → ถ้าค่าใหม่มากกว่าให้แทน best → พิมพ์ best. ต้องเริ่มจากค่าจริงที่มีอยู่ และดูทุกช่องหลังจากนั้น
- อาเรย์สองมิติ int grid[2][3] มีกี่ช่องรวม
  - a) 6  b) 5  c) 23  — เฉลย: a. 2 คูณ 3 เท่ากับ 6
**โจทย์**
- **ผลรวม** — ประกาศอาเรย์ 3, 5, 7 แล้วพิมพ์ผลรวมเป็น 15. ผลลัพธ์ที่ได้: `15`. คำใบ้: ใช้ลูปผ่านทุกช่องบวกเข้า total
- **ตำแหน่งค่ามาก** — ในอาเรย์ 3, 8, 1, 9, 4 พิมพ์ตำแหน่งของค่าที่มากที่สุด. ผลลัพธ์ที่ได้: `3`. คำใบ้: เก็บ index ของค่าที่ดีที่สุดแทนการเก็บค่า
- **กริดสองมิติ** — สร้าง grid[2][3] โดย grid[r][c] = r * 3 + c แล้วพิมพ์ผลรวมทุกช่อง. ผลลัพธ์ที่ได้: `15`. คำใบ้: วนลูปซ้อนสองชั้นแล้วบวกเข้า total

## สตริง
**คืออะไร.** String คือข้อความที่ขยายได้ ต่อด้วย + ได้ .len บอกความยาวเป็นไบต์ s[i] คือตัวอักษรที่ตำแหน่ง i นับจาก 0 เมธอดที่ใช้บ่อยคือ push เพิ่มตัวอักษรท้าย find หาตำแหน่ง slice ตัดช่วง และ to_int แปลงเป็นตัวเลข การเปรียบเทียบด้วย == ทำกับข้อความได้โดยตรง
**ทำไมต้องรู้.** โปรแกรมส่วนใหญ่ทำงานกับข้อความ เช่นอ่านไฟล์ แยกคำ หรือตรวจรหัส การรู้ว่า .len นับไบต์และ find คืนตำแหน่งจาก 0 ช่วยหลีกเลี่ยงบั๊กตัดข้อความผิด
**ทำอย่างไร.**

ต่อข้อความด้วย + เก็บตัวอักษรที่อยากได้ด้วย s[i] แล้วนับจำนวนตัวอักษรด้วยลูป
```jk
String word = "banana";
int count = 0;
for i in 0..word.len {
    if word[i] == 'a' { count++; }
}
jout << count << "\n";
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    String first = "J2K";
    String title = first + " basics";
    jout << title << " " << title.len << " " << title[0] << "\n";
    if first == "J2K" { jout << "same\n"; }
    String line = "Hello, Jao";
    jout << line.find("Jao") << " " << line.slice(0, 5) << "\n";
    int n = "42".to_int();
    jout << n + 1 << "\n";
}
```

```
J2K basics 10 J
same
7 Hello
43
```

> **ระวัง:** อย่าลืมว่า s[i] เป็นตัวอักษร (char) เทียบกับ 'a' ในเครื่องหมายคำพูดเดี่ยว ไม่ใช่ "a" ในคู่ เพราะ "a" เป็น String และการเทียบไม่ตรงชนิด
**แบบฝึกหัด**
- "abc".len คือค่าเท่าใด
  - a) 3  b) 2  c) 4  — เฉลย: a. len นับจำนวนตัวอักษร ซึ่งสำหรับภาษาอังกฤษเท่ากับจำนวนไบต์
- ตัวอักษรในเครื่องหมายคำพูดเดี่ยวกับคู่เป็นสิ่งเดียวกัน — เฉลย: f. เครื่องหมายเดี่ยวคือ char หนึ่งตัว คู่คือ String ซึ่งเป็นคนละชนิด
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
String s = "ab";
s.push('c');
jout << s << "\n";
}
```
  ผลลัพธ์ที่ได้: `abc`. push เพิ่มตัวอักษรต่อท้ายข้อความเดิม
- เมธอดที่แปลงข้อความที่เป็นตัวเลขเป็น int คือ ___ — เฉลย: **to_int**. to_int ใช้ได้กับ String
- การตัดคำว่า world จาก hello world: หาตำแหน่งของช่องว่างด้วย find → ตำแหน่งบวกหนึ่ง → ตัดด้วย slice จนถึงความยาว → พิมพ์ผล. ตำแหน่งหลังช่องว่างคือจุดเริ่มของคำที่ต้องการ
- "42".to_int() ให้ค่าเท่าไร
  - a) 42  b) "42"  c) 4  — เฉลย: a. เมธอดแปลงข้อความเป็นตัวเลข ได้ 42 เป็นจำนวนเต็ม
**โจทย์**
- **นับ a** — เขียนโปรแกรมนับตัว a ในคำว่า banana แล้วพิมพ์ a 3. ผลลัพธ์ที่ได้: `a 3`. คำใบ้: ใช้ word[i] == 'a'
- **กลับคำ** — กลับคำว่า abc เป็น cba โดยวนจากท้ายและ push ตัวอักษร แล้วพิมพ์ผล. ผลลัพธ์ที่ได้: `cba`. คำใบ้: วนตั้งแต่ความยาวลบหนึ่งถึงศูนย์
- **ตัดคำ** — จาก "hello world" พิมพ์คำที่อยู่หลังช่องว่าง. ผลลัพธ์ที่ได้: `world`. คำใบ้: ใช้ find ของช่องว่างแล้ว slice

## ขอบเขตของตัวแปร
**คืออะไร.** ตัวแปรมีชีวิตตั้งแต่บรรทัดที่ประกาศจนถึงปีกกาปิดของบล็อกที่มันอยู่ ตัวแปรนอกทุกฟังก์ชันเรียกว่า global มองเห็นได้ทุกที่ ตัวแปรในฟังก์ชันหรือในลูปเรียกว่า local ในลูปตัวแปรใหม่ถูกสร้างใหม่ทุกรอบ
**ทำไมต้องรู้.** ถ้าตัวแปรถูกใช้นอกขอบเขต คอมไพเลอร์จะบอกว่าไม่รู้จัก และการใช้ตัวแปร global มากทำให้หาไม่ได้ว่าใครเปลี่ยนค่า ขอบเขตจึงช่วยให้โค้ดแยกส่วนกัน
**ทำอย่างไร.**

ประกาศตัวแปรในบล็อกที่ใช้มัน ถ้าต้องใช้ข้ามฟังก์ชันจึงค่อยประกาศไว้ด้านนอก
```jk
int total = 100;
void main() {
    if total > 3 {
        int inner = total + 1;
    }
}
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

int total = 100;

int twice(int x) {
    int result = x * 2;
    return result;
}

void main() {
    int n = 5;
    if n > 3 {
        int inner = n + 1;
        jout << "inner = " << inner << "\n";
    }
    for i in 0..3 {
        int sq = i * i;
        jout << "sq = " << sq << "\n";
    }
    jout << twice(n) << " " << total << "\n";
}
```

```
inner = 6
sq = 0
sq = 1
sq = 4
10 100
```

> **ระวัง:** ถ้าพิมพ์ inner หลังปีกกาปิดของ if จะได้ข้อความว่าไม่รู้จักชื่อนี้ นั่นคือกฎขอบเขตทำงาน ดูข้อความให้ละเอียดเพื่อหาว่าตัวแปรประกาศอยู่ที่ใด
**แบบฝึกหัด**
- ตัวแปรที่ประกาศในฟังก์ชัน twice ใช้ในฟังก์ชัน main ได้หรือไม่
  - a) ไม่ได้  b) ได้  c) ได้เฉพาะถ้าเป็น int  — เฉลย: a. ตัวแปร local มีขอบเขตเฉพาะในฟังก์ชันหรือบล็อกของมัน
- ตัวแปร global เปลี่ยนได้จากทุกฟังก์ชัน — เฉลย: t. global มองเห็นได้ทุกที่ จึงเปลี่ยนได้จากทุกฟังก์ชัน และทำให้หาสาเหตุยาก
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

int g = 10;

void main() {
for i in 0..2 {
    int x = i + g;
    jout << x << "\n";
}
}
```
  ผลลัพธ์ที่ได้: `10 / 11`. g เป็น global ค่า 10 และ x ถูกสร้างใหม่ทุกรอบ จึงได้ 10 แล้ว 11
- ตัวแปรที่ประกาศนอกทุกฟังก์ชันเรียกว่า ___ — เฉลย: **global**. global เป็นตัวแปรที่มองเห็นได้ทุกที่
- วงจรชีวิตของ local ในลูป: เข้าลูปรอบแรก → สร้าง local ใหม่ → ใช้ค่าในรอบนั้น → ออกจากบล็อกแล้วค่าหาย. ทุกรอบสร้างใหม่ และหายเมื่อจบบล็อก
- ทำไมควรใช้ local มากกว่า global
  - a) เพราะเห็นได้ชัดว่าใครเปลี่ยนค่า  b) เพราะเร็วกว่าเสมอ  c) เพราะ global ใช้ไม่ได้  — เฉลย: a. local ถูกจำกัดให้เห็นในที่เดียว ทำให้ตรวจผิดง่ายและอ่านง่ายกว่า
**โจทย์**
- **นับจากฟังก์ชัน** — ใช้ตัวแปร global counter เริ่มที่ 0 แล้วฟังก์ชัน bump เพิ่มค่าหนึ่งครั้ง เรียก bump สามครั้งแล้วพิมพ์ counter 3. ผลลัพธ์ที่ได้: `counter 3`. คำใบ้: ฟังก์ชัน bump ต้องเขียนค่า global
- **ผลรวมกำลังสอง** — วน i ใน 0..4 สร้าง local sq = i * i แล้วรวม sum แล้วพิมพ์ sum 14. ผลลัพธ์ที่ได้: `sum 14`. คำใบ้: local sq ใหม่ทุกรอบ รวมค่า 0, 1, 4, 9 ได้ 14

## struct: กลุ่มของค่า
**คืออะไร.** struct รวมหลายค่าเป็นชนิดเดียว ค่าที่อยู่ข้างในเรียกว่า field ตั้งค่าด้วยวงเล็บปีกกาตามลำดับ เช่น Rect r = {3, 4}; ฟังก์ชันที่อยู่ใน struct เรียกว่า method และรับ self เป็นอ็อบเจกต์นั้น
**ทำไมต้องรู้.** ข้อมูลหนึ่งเรื่องมักมีหลายส่วน เช่น จุดมี x และ y บัญชีมีเจ้าของและยอดเงิน การจัดเป็น struct ทำให้โค้ดชัดว่าค่าเหล่านี้เป็นของสิ่งเดียวกัน
**ทำอย่างไร.**

ประกาศ struct พร้อม field และ method แล้วสร้างค่าด้วย วงเล็บปีกกา
```jk
#import <stdlib>
using stdlib;

struct Rect {
    int w;
    int h;
    int area(self) {
        return self.w * self.h;
    }
}

void main() {
    Rect r = {3, 4};
    jout << r.area() << "\n";
}
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

struct Rect {
    int w;
    int h;

    int area(self) {
        return self.w * self.h;
    }

    void grow(self, int d) {
        self.w += d;
        self.h += d;
    }
}

void main() {
    Rect r = {3, 4};
    jout << r.area() << "\n";
    r.grow(1);
    jout << r.w << "x" << r.h << " area " << r.area() << "\n";
}
```

```
12
4x5 area 20
```

> **ระวัง:** method ที่เปลี่ยน field ต้องรับ self และเรียกด้วยจุด ถ้าลืม self ตัวแปรจะไม่ถูกเปลี่ยนจริง และถ้าค่าในวงเล็บปีกกา น้อยกว่าจำนวน field จะเกิดข้อผิดพลาด
**แบบฝึกหัด**
- field ใน struct คืออะไร
  - a) ค่าที่เก็บอยู่ในอ็อบเจกต์  b) ชื่อของโปรแกรม  c) ฟังก์ชันพิเศษ  — เฉลย: a. field คือส่วนประกอบของข้อมูลในอ็อบเจกต์ เช่น w และ h
- method สามารถเปลี่ยน field ของอ็อบเจกต์ได้โดยรับ self — เฉลย: t. self ทำให้ method เข้าถึงอ็อบเจกต์ที่เรียกอยู่ และแก้ไข field ได้
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

struct Point {
int x;
int y;
}

void main() {
Point p = {3, 4};
jout << p.x + p.y << "\n";
}
```
  ผลลัพธ์ที่ได้: `7`. ค่าในวงเล็บปีกกาถูกใส่เข้า field ตามลำดับ x เป็น 3 และ y เป็น 4 รวมได้ 7
- ฟังก์ชันที่อยู่ใน struct เรียกว่า ___ — เฉลย: **method**. method ทำงานกับอ็อบเจกต์หนึ่งชิ้น
- การสร้างและใช้ Rect: ประกาศ struct ที่มี field → สร้าง r ด้วย {3, 4} → เรียก r.area() → พิมพ์ผล. ต้องมีนิยาม struct ก่อนสร้างค่า และสร้างค่าก่อนเรียก method
- ถ้า method ไม่มี self จะเกิดอะไร
  - a) ไม่รู้ว่าอ็อบเจกต์ไหน จึงเข้าถึง field ไม่ได้  b) ทำงานเร็วขึ้น  c) ทุกอ็อบเจกต์เปลี่ยน  — เฉลย: a. self คือการบอกว่า method ทำงานกับอ็อบเจกต์ใด
**โจทย์**
- **จุดสองพิกัด** — สร้าง Point p = {3, 4} แล้วพิมพ์ผลรวม x กับ y เป็น 7. ผลลัพธ์ที่ได้: `7`. คำใบ้: ใช้ p.x + p.y
- **พื้นที่** — เพิ่ม method area ที่คืน w * h ให้ Rect แล้วพิมพ์ area ของ {5, 6}. ผลลัพธ์ที่ได้: `30`. คำใบ้: ใช้ self.w * self.h
- **บัญชี** — struct Account ที่มี balance เริ่มเป็น 100 และ method deposit(self, int x) เพิ่มยอด แล้วฝาก 25 และพิมพ์ balance 125. ผลลัพธ์ที่ได้: `balance 125`. คำใบ้: method ต้องมี self เพื่อเพิ่มค่าของ balance

## enum และ switch
**คืออะไร.** enum class คือรายการชื่อที่ตั้งไว้ล่วงหน้า switch เลือกกรณีที่ตรงกับค่า ไม่มีการตกลงไปกรณีถัดไป (ไม่มี fall-through) _ คือกรณีที่เหลือทั้งหมด enum ไม่ใช่ตัวเลข ทำให้ไม่สับสนกับตัวเลขโดยไม่ตั้งใจ
**ทำไมต้องรู้.** ค่าที่เป็นตัวเลือกจำนวนจำกัด เช่นทิศ สถานะ หรือวัน ควรเป็น enum ถ้าใช้ตัวเลขดิบ เช่น 2 หมายถึงอะไรจะจำไม่ได้ และคอมไพเลอร์เตือนได้เมื่อลืมกรณี
**ทำอย่างไร.**

ประกาศรายชื่อ แล้วเขียนกรณีด้วย Enum::ชื่อ
```jk
#import <stdlib>
using stdlib;

enum class Light { Red, Yellow, Green };

void say(Light l) {
    switch l {
        Light::Red: jout << "stop\n";
        Light::Green: jout << "go\n";
        _: jout << "slow\n";
    }
}

void main() {
    say(Light::Red);
}
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

enum class Light { Red, Yellow, Green };

void say(Light l) {
    switch l {
        Light::Red: jout << "stop\n";
        Light::Yellow: jout << "slow down\n";
        Light::Green: jout << "go\n";
    }
}

void main() {
    say(Light::Green);
    say(Light::Red);
    int n = 3;
    switch n {
        1, 2: jout << "small\n";
        3: jout << "three\n";
        _: jout << "other\n";
    }
}
```

```
go
stop
three
```

> **ระวัง:** ถ้า switch กับ enum ลืมกรณีหนึ่ง คอมไพเลอร์จะเตือน ให้อ่านข้อความเตือนและเพิ่มกรณีที่ขาด อย่าใช้ _ ปิดการเตือนทั้งหมด
**แบบฝึกหัด**
- switch ทำงานอย่างไรเมื่อตรงกรณี
  - a) ทำเฉพาะกรณีนั้นแล้วออก  b) ทำทุกกรณีต่อจากนั้น  c) ไม่ทำอะไร  — เฉลย: a. J2K ไม่ตกลงไปกรณีถัดไป จึงไม่ต้องใส่ break
- enum class Light คือตัวเลข 0 1 2 ที่ใช้คำนวณได้ — เฉลย: f. enum ไม่ใช่ตัวเลข ป้องกันการสับสน ต้องใช้ switch หรือการเปรียบเทียบที่ตั้งใจเท่านั้น
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

enum class Heading { North, South };

void main() {
Heading d = Heading::South;
switch d {
    Heading::North: jout << "up\n";
    Heading::South: jout << "down\n";
}
}
```
  ผลลัพธ์ที่ได้: `down`. ค่า d คือ South จึงทำกรณี South
- กรณีที่เหลือทั้งหมดใน switch เขียนด้วยสัญลักษณ์ ___ — เฉลย: **_**. _ คือกรณี default ที่ทำเมื่อไม่มีกรณีอื่นตรง
- การใช้ enum กับ switch: ประกาศ enum class → สร้างค่า Light::Green → ส่งเข้า say → switch เลือกกรณีที่ตรง. ต้องมี enum ก่อนใช้ และค่าต้องถูกสร้างก่อนส่ง
- ทำไม enum ดีกว่าตัวเลขดิบสำหรับสถานะ
  - a) อ่านและตรวจได้ง่าย และคอมไพเลอร์ช่วยเช็ก  b) เร็วกว่าเสมอ  c) ไม่ต้องใช้ switch  — เฉลย: a. ชื่อที่มีความหมายทำให้โค้ดชัด และคอมไพเลอร์เตือนกรณีที่หายไป
**โจทย์**
- **ทิศ** — enum class Heading { North, South, East } แล้ว switch ให้พิมพ์ east ถ้า d เป็น East. ผลลัพธ์ที่ได้: `east`. คำใบ้: เขียนกรณี Heading::East แล้วพิมพ์ east
- **วันในสัปดาห์** — switch บน int n ให้พิมพ์ one เมื่อ n เป็น 1, two เมื่อ n เป็น 2, other เมื่ออย่างอื่น แล้วทดสอบด้วย 2. ผลลัพธ์ที่ได้: `two`. คำใบ้: ใช้ 2: แล้วกรณี _ สำหรับที่เหลือ
- **รูปร่าง** — enum class Shape { Circle(double r), Empty } และ method area คืน 3.0 * r * r สำหรับ Circle และ 0.0 สำหรับ Empty แล้วพิมพ์ area ของ Circle(2.0). ผลลัพธ์ที่ได้: `12.000000`. คำใบ้: ใช้ switch self^ ใน method

## Option และ Result
**คืออะไร.** Option<T> ใช้เมื่ออาจไม่มีค่า มีค่าหรือไม่มี และตรวจด้วย is_some หรือ is_none Result<T, Error> ใช้เมื่อการทำงานอาจล้มเหลว ได้ Ok พร้อมค่า หรือ Err พร้อมเหตุผล เครื่องหมาย ? ส่งข้อผิดพลาดกลับไปให้ผู้เรียกทันที และถ้าสำเร็จจะได้ค่าไปใช้ต่อ
**ทำไมต้องรู้.** ฟังก์ชันที่อ่านไฟล์หรือตัวแปรสภาพแวดล้อมอาจไม่มีผลลัพธ์ Option และ Result ทำให้คุณต้องคิดถึงกรณีล้มเหลวอย่างชัดเจน แทนที่จะได้ค่าขยะเงียบ ๆ
**ทำอย่างไร.**

เมื่อได้ Result ให้ใช้ switch แยกกรณี Ok และ Err หรือใช้ ? ถ้าต้องการส่งต่อ
```jk
#import <stdlib>
using stdlib;

void show(Result<int, Error> r) {
    switch r {
        Result::Ok(v): jout << "sum = " << v << "\n";
        Result::Err(e): jout << "error: " << e.message << "\n";
    }
}

void main() {
    show(Result<int, Error>::Ok(42));
}
```
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

Result<int, Error> parse(String s) {
    if s.len == 0 { return Result<int, Error>::Err(Error::make(ErrorKind::Invalid, "empty text")); }
    return Result<int, Error>::Ok(s.to_int());
}

Result<int, Error> add(String a, String b) {
    int x = parse(a)?;
    int y = parse(b)?;
    return Result<int, Error>::Ok(x + y);
}

void show(Result<int, Error> r) {
    switch r {
        Result::Ok(v): jout << "sum = " << v << "\n";
        Result::Err(e): jout << "error: " << e.message << "\n";
    }
}

void main() {
    show(add("20", "22"));
    show(add("20", ""));
    Option<String> home = Env::get("J2K_SURELY_NOT_SET");
    jout << home.is_none() << "\n";
}
```

```
sum = 42
error: empty text
true
```

> **ระวัง:** ถ้าใช้ unwrap กับ Option ที่ว่าง โปรแกรมจะล้มเหลว ควรเช็ก is_some ก่อนหรือใช้ or(ค่าสำรอง) แทน
**แบบฝึกหัด**
- ? ทำอะไรกับ Result ที่เป็น Err
  - a) ส่ง Err กลับไปให้ผู้เรียกทันที  b) เปลี่ยนเป็น Ok  c) ไม่ทำอะไร  — เฉลย: a. ? ส่งข้อผิดพลาดต่อขึ้นไปและจบฟังก์ชันนั้น ถ้าเป็น Ok จะคืนค่าข้างใน
- Option ที่ว่างเป็นค่าศูนย์เสมอ — เฉลย: f. Option ที่ไม่มีค่าไม่ใช่ศูนย์ มันเป็นสถานะไม่มีค่า ต้องเช็กด้วย is_none
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
Option<String> v = Env::get("J2K_SURELY_NOT_SET");
jout << v.is_some() << "\n";
}
```
  ผลลัพธ์ที่ได้: `false`. ตัวแปรนี้ไม่ได้ตั้งไว้ จึงไม่มีค่า is_some ให้ false
- การส่งข้อผิดพลาดต่อขึ้นไป ซึ่งเขียนด้วยเครื่องหมาย ? ในภาษาอังกฤษเรียกว่า ___ — เฉลย: **propagate**. ? ทำให้ฟังก์ชันคืน Err ทันทีถ้าเจอข้อผิดพลาด
- การใช้ Result ของฟังก์ชัน add: parse ส่งกลับ Result → ? ตรวจว่า a เป็น Ok → ? ตรวจ b → คืน Ok ผลรวม. ถ้าขั้นใดเป็น Err ฟังก์ชันจะจบก่อนไปขั้นถัดไป
- ทำไมต้องเขียน Result<int, Error>
  - a) เพื่อบอกชนิดของค่าที่สำเร็จและชนิดของข้อผิดพลาด  b) เพราะ int ไม่พอ  c) เพราะเป็นชื่อฟังก์ชัน  — เฉลย: a. Result มีสองชนิดในตัว ชนิดที่ถูกต้องและชนิดของข้อผิดพลาด ต้องเขียนให้ครบ
**โจทย์**
- **Result ของจำนวน** — เขียนฟังก์ชัน parse ที่คืน Ok ของ s.to_int() และ switch พิมพ์ value 12 เมื่อ parse("12") สำเร็จ. ผลลัพธ์ที่ได้: `value 12`. คำใบ้: ใช้ Result<int, Error>::Ok และ switch กรณี Ok
- **ต่อด้วย ?** — เขียน add(a, b) ที่ใช้ parse กับ ? แล้วพิมพ์ผลรวม 5 ของ "2" และ "3". ผลลัพธ์ที่ได้: `sum 5`. คำใบ้: ใช้ int x = parse(a)?; แล้วคืน Ok(x + y)
- **ค่าสำรอง** — Option จาก Env::get ของ J2K_NOT_HERE ให้ค่าสำรองเป็น none ด้วย or แล้วพิมพ์ผล. ผลลัพธ์ที่ได้: `none`. คำใบ้: เมธอด or(ค่าสำรอง) ให้ค่าที่กำหนดเมื่อว่าง

## อ่านข้อความแสดงข้อผิดพลาดของคอมไพเลอร์
**คืออะไร.** ข้อความของคอมไพเลอร์มีรูปแบบ ไฟล์:บรรทัด:คอลัมน์: error: เกิดอะไรขึ้น บรรทัดถัดมาแสดงโค้ดและเครื่องหมาย ^ ชี้ตำแหน่ง บรรทัด help: บอกวิธีแก้ที่แนะนำ ข้อความแรกสำคัญที่สุด เพราะข้อความถัดไปมักเกิดจากข้อแรก
**ทำไมต้องรู้.** ทุกคนจะเจอข้อผิดพลาดของคอมไพเลอร์ทุกวัน ถ้าอ่านข้อความเป็น คุณจะแก้เร็วกว่าการเดาเป็นชั่วโมง โดยเฉพาะการแก้ข้อแรกแล้วคอมไพล์ใหม่
**ทำอย่างไร.**

อ่านข้อความแรกก่อน ไปดูบรรทัดที่ระบุ ชี้ของเครื่องหมาย ^ ชี้ตรงไหน แล้วทำตาม help ถ้ามี จากนั้นคอมไพล์ใหม่
ตัวอย่างข้อความที่ขาดเซมิโคลอนจะบอกว่าคำสั่งยังไม่จบที่บรรทัดนั้น ให้เพิ่มเซมิโคลอนท้ายบรรทัด
**ตัวอย่าง.**

```jk
#import <stdlib>
using stdlib;

void main() {
    // the first error is the one to fix: this version compiles and prints
    int count = 5;
    jout << "count " << count << "\n";
}
```

```
count 5
```

> **ระวัง:** อย่าแก้ข้อความที่สองหรือสามก่อน ข้อความเหล่านั้นอาจหายไปเองเมื่อแก้ข้อแรก ให้แก้ทีละข้อ แล้วคอมไพล์ใหม่ทุกครั้ง
**แบบฝึกหัด**
- ควรแก้ข้อผิดพลาดของคอมไพเลอร์เริ่มจากข้อใด
  - a) ข้อความแรกสุด  b) ข้อความสุดท้าย  c) ข้อที่ยาวที่สุด  — เฉลย: a. ข้อแรกเป็นต้นเหตุ ข้อหลังอาจเป็นผลต่อเนื่อง
- ตัวชี้ ^ ในข้อความบอกตำแหน่งที่คอมไพเลอร์พบปัญหา — เฉลย: t. ^ อยู่ใต้ตัวอักษรที่คอมไพเลอร์ไม่เข้าใจ
- ทายผลลัพธ์ของโค้ด:

```jk
#import <stdlib>
using stdlib;

void main() {
int n = 2;
jout << n * 3 << "\n";
}
```
  ผลลัพธ์ที่ได้: `6`. ไม่มีข้อผิดพลาด โค้ดคูณ 2 ด้วย 3 ได้ 6
- บรรทัดที่เริ่มด้วย help: ในข้อความของคอมไพเลอร์บอก ___ ที่แนะนำ — เฉลย: **fix**. help บอกวิธีแก้ที่คอมไพเลอร์แนะนำ
- วิธีแก้ข้อผิดพลาดของคอมไพเลอร์: อ่านข้อความแรก → ไปดูบรรทัดและ ^ → แก้ตาม help หรือความเข้าใจ → คอมไพล์ใหม่. การคอมไพล์ใหม่ทำให้เห็นว่าข้อผิดพลาดหายหรือยังเหลือ
- รูปแบบ file:3:5: error หมายถึงอะไร
  - a) ไฟล์ บรรทัด 3 คอลัมน์ 5 มีข้อผิดพลาด  b) ไฟล์มีห้าบรรทัด  c) ผู้เขียนคือหมายเลข 3  — เฉลย: a. ตัวเลขแรกคือบรรทัด ตัวเลขที่สองคือคอลัมน์
**โจทย์**
- **แก้ชนิด** — เก็บเลข 5 ใน int count แล้วพิมพ์ count 5. ผลลัพธ์ที่ได้: `count 5`. คำใบ้: ตัวแปรต้องเป็น int และค่าต้องเป็นตัวเลข
- **แก้ชื่อ** — ประกาศ total เป็น 9 แล้วพิมพ์ total 9. ผลลัพธ์ที่ได้: `total 9`. คำใบ้: ใช้ชื่อเดียวกันทั้งการประกาศและการพิมพ์
- **ตรวจหลังแก้** — เขียนโปรแกรมที่พิมพ์ ok และขึ้นบรรทัดใหม่. ผลลัพธ์ที่ได้: `ok`. คำใบ้: jout หนึ่งครั้ง
