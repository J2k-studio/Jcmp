# วิชาวิทยาการคอมพิวเตอร์ด้วย J2K: ความลึก 0 ถึง 100

หน้านี้จับคู่หัวข้อวิชา CS ปกติกับบทสอนในรีโพนี้ เพื่อให้เรียนเนื้อหา*และ*ภาษาไปพร้อมกัน ทุกบทเป็นโปรแกรมเล็กที่คอมไพล์และรันบนมือถือได้ เลขบทตาม [TUTORIAL.th.md](TUTORIAL.th.md) ส่วน `B0`..`B9` คือบทของ [BASICS.th.md](BASICS.th.md)

| ความลึก | สิ่งที่เข้าใจ | อยู่ที่ |
|---|---|---|
| 0 - 20 | เขียนโปรแกรมได้ | B0-B9, บท 1-23, 151-154 |
| 21 - 40 | เลือกโครงสร้างข้อมูล/อัลกอริทึมได้ | บท 14-16, 141-143, 155-162 |
| 41 - 60 | รู้ว่าเครื่องและ OS ทำงานยังไง | บท 30-48, 76-83, 163 |
| 61 - 80 | ออกแบบระบบและเร่งประสิทธิภาพได้ | บท 57-75, 84-90, 91-150 |
| 81 - 100 | สร้างเครื่องมือระดับต่ำหรือระบบใหม่ได้ | บท 45-48, 80-82, [ARCHITECTURE.md](ARCHITECTURE.md), ส่วน Jaric OS |

## เก้าวิชา

**1. พื้นฐานคิดแบบคอมพิวเตอร์** (แก้ปัญหา, logic, Big-O, อัลกอริทึมถูก/ผิด): บท 155 (นับขั้นตอน), 132 (เทสฟังก์ชันของตัวเอง), 154 (แก้บั๊กด้วยการดูค่า)

**2. เขียนโปรแกรม** (ตัวแปร เงื่อนไข ลูป ฟังก์ชัน โครงสร้างข้อมูล ออกแบบโปรแกรม): B0-B9, บท 1-13, 131, 146-148

**3. โครงสร้างข้อมูลและอัลกอริทึม** (array, list, stack, queue, tree, graph, hash; ค้นหา เรียง กราฟ DP; เวลา/หน่วยความจำ): บท 15 (ลิสต์ แมป เซ็ต), 143 (เรียงด้วยการเปรียบเทียบของเรา), 141 (heap), 142 (hash map), 153 (binary search), 156 (stack), 157 (queue), 158 (ต้นไม้ค้นหา), 159 (กราฟและ BFS), 160 (DP), 161 (ตารางแฮชเขียนเอง), 162 (เรียงสองแบบนับการเปรียบเทียบ)

**4. ระบบคอมพิวเตอร์** (เลขฐานสอง, CPU, หน่วยความจำ, cache, assembly, compiler เบื้องต้น): บท 76-82 (ฐาน 2, two's complement, logic gate, CPU จิ๋ว, assembler), 30 (บิต), 32 (โค้ดที่คอมไพเลอร์สร้าง), 35-48 (รีจิสเตอร์ แฟลก คำสั่งดิบ), 163 (cache), 109 (cache ในผลคูณเมทริกซ์), [ARCHITECTURE.md](ARCHITECTURE.md) (คอมไพเลอร์นี้สร้างอย่างไร)

**5. ระบบปฏิบัติการ** (process/thread, หน่วยความจำ, ไฟล์ซิสเต็ม, scheduling, concurrency): บท 34 (thread และ atomic), 40 (คุยกับ kernel), 41 (allocator ของเราเอง), 42 (spinlock), 45 (สองงาน สองสแตก: context switch), 46 (คิวไม่มีล็อก), 19 และ 29 (ไฟล์และ path) ส่วน scheduling และไฟล์ซิสเต็มตั้งแต่ศูนย์ *ยังไม่ได้เขียน*

**6. เครือข่าย** (TCP/IP, HTTP, ลูกข่าย-เซิร์ฟเวอร์, ความล่าช้า bandwidth): บท 67-69 (เว็บ บอต WebSocket), [INTEROP.md](INTEROP.md) บทเรื่อง socket ตั้งแต่ต้นและเรื่อง delay/bandwidth *ยังไม่ได้เขียน*

**7. ฐานข้อมูล** (โมเดลข้อมูล, query, transaction, index): บท 26-27 (JSON, CSV), 142 (hash map คือ index) เอนจินฐานข้อมูลเล็ก (ตาราง index และ log ธุรกรรม) *ยังไม่ได้เขียน*

**8. วิศวกรรมซอฟต์แวร์** (ออกแบบ ทดสอบ เวอร์ชัน คุณภาพโค้ด): บท 20 และ 131 (หลายไฟล์), 132 (เทส), 57 (ไฟล์ build), 75 (แพ็กเกจ), [CONTRIBUTING.md](CONTRIBUTING.md), [STYLE.md](STYLE.md)

**9. สาขาลึกเฉพาะทาง**
* AI / ML: บท 70-73 และ 111-130, [TRAIN_AI.md](TRAIN_AI.md)
* กราฟิก/เกม: บท 62-66, 84, 88, 145, [GPU.md](GPU.md)
* ความปลอดภัย: บท 28 และ 89 (แฮช กุญแจ), บทเรื่องการเขียนอย่างปลอดภัย *ยังไม่ได้เขียน*
* Compiler: บท 32, 139-140 (tokenizer และเครื่องคิดเลข recursive-descent), [ARCHITECTURE.md](ARCHITECTURE.md)
* Embedded/systems: บท 35-48, [SYSTEMS.md](SYSTEMS.md), [SIMD.md](SIMD.md)
* Distributed systems: *ยังไม่ได้เขียน*

## ความเร็วทีละขั้น (ผลคูณเมทริกซ์เป็นหลักสูตร)

ผลคูณเมทริกซ์เป็นโปรแกรมเดียวที่ดีที่สุดสำหรับเรียนว่าคอมพิวเตอร์ทำงานอย่างไร เพราะทุกระดับของเครื่องปรากฏอยู่ในนั้น อ่านตามลำดับ: 97 (แบบธรรมดา), 98 (ทำไมโซ่การบวกช้า), 99 (สี่ตัวสะสม), 100 (สี่คอลัมน์พร้อมกันด้วยเวกเตอร์), 101 (บล็อกรีจิสเตอร์ 4 x 8), 109 (ลำดับลูปและ cache), 102 (thread), 110 (เทียบกับ C ให้ยุติธรรม), 130 (ทำไมโครงข่ายประสาทคือผลคูณเมทริกซ์) และ [PERFORMANCE.md](PERFORMANCE.md)

ที่วัดบนมือถือเครื่องหนึ่ง (384 x 384, float32, ลำดับลูปเทียบ C -O2, มีความแกว่ง): ลำดับที่ลูปในเดินตามแถว (`ikj`, `kij`) เร็วเท่า C หรือเร็วกว่า ลำดับ dot product (`ijk`, `jik`) ช้ากว่า C 1.5 ถึง 2 เท่า และเป็นสิ่งถัดไปที่คอมไพเลอร์ต้องแก้ เคอร์เนล 4 x 8 ของ `<neuron>` ได้ 14 GFLOPS ต่อแกน เท่ากับโปรแกรม C ที่เขียนด้วยคำสั่ง NEON เดียวกัน

## ที่ยังขาด เรียงตามที่ผมจะเขียน
1. scheduling และไฟล์ซิสเต็มจิ๋ว (OS ความลึก 41-60)
2. socket ตั้งแต่ต้น, latency และ bandwidth (เครือข่าย)
3. ฐานข้อมูลเล็ก: ตาราง index log (ฐานข้อมูล)
4. เขียนอย่างปลอดภัย: ขอบเขตบัฟเฟอร์ ตรวจอินพุต (ความปลอดภัย)
5. ระบบกระจาย: สองโปรเซส ข้อความ และความล้มเหลว (ความลึก 81-100)
