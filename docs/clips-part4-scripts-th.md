# สคริปต์คลิป ภาค 4 "ใช้งานได้เลย" (ร่าง 2026-11-05, แก้ได้)

แต่ละคลิป 5-8 นาที พูดไทย ศัพท์อังกฤษ ใช้โปรแกรมจาก `docs/TUTORIAL.md` (ตรงกับบทเรียนเลขเดียวกัน) เพื่อให้ผู้ดูพิมพ์ตามได้
ตารางคลิป -> บทเรียน: 1 ติดตั้ง+hello (L1) · 2 ตัวแปรและเลข (L2) · 3 if (L3) · 4 loop (L4) · 5 ฟังก์ชัน (L5) · 6 array/string (L6, L13) · 7 struct (L9) · 8 ไฟล์ (L19) · 9 แอปแรกด้วย `makej init -apk` · 10 ส่งขึ้น GitHub

## คลิป 1: ติดตั้งและ Hello (5 นาที)
1. (0:00) บอกว่า J2K คือภาษาที่คอมไพล์เป็นโค้ดเครื่องตรงๆ ไม่มี libc จบคลิปนี้จะรันโปรแกรมแรกได้
2. (0:30) พิมพ์ `curl -fsSL https://raw.githubusercontent.com/J2k-studio/Jcmp/main/install.sh | sh` ; รัน `jcmp --version`
3. (1:30) สร้าง `hello.jk` ตามบทเรียน 1 (`#import <stdlib>` + `jout`) ; `jcmp hello.jk -o hello && ./hello`
4. (3:00) แสดงว่าไฟล์ผลลัพธ์เล็กแค่ไหน (`ls -l hello`) ; `jcmp hello.jk -show main` ให้เห็นแอสเซมบลีสั้นๆ
5. (4:15) ข้อความผิดพลาด: ลบ `;` หรือพิมพ์ชื่อผิด ให้เห็นรูปแบบ `ไฟล์:บรรทัด:คอลัมน์: error: ...`
6. (4:45) สรุปบรรทัดเดียวบนจอ: "เขียน -> jcmp -> รัน"

## คลิป 2: ตัวแปรและเลข (6 นาที)
1. int, decimal, ข้อความ ; พิมพ์ผลบวก/ลบ/คูณ/หาร และเศษ (`%`) จากบทเรียน 2
2. ข้อผิดพลาดที่พบบ่อย: หารด้วยศูนย์ใน int (ให้เห็นว่าโปรแกรมหยุดพร้อมข้อความ) 
3. สรุป: "ทุกอย่างคือตัวเลข ชนิดบอกว่าอ่านมันอย่างไร"

## คลิป 3: ตัดสินใจด้วย if (6 นาที)
1. `if / else if / else`, เทียบเลข, `and` `or` `not` จากบทเรียน 3
2. โปรแกรมเล็ก: บอกเกรดจากคะแนน (พิมพ์สดไม่เกิน 15 บรรทัด)
3. สรุป: "เงื่อนไขคือคำถามที่ตอบจริงหรือเท็จ"
