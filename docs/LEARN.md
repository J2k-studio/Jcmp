# เรียนจากศูนย์: เส้นทางเดียว ไม่กระโดด

หน้านี้ตอบคำถาม "ผมไม่เคยเขียนโปรแกรมเลย จะเริ่มตรงไหน แล้วไปทางไหนต่อ" เรียงเป็นเส้นเดียว แต่ละขั้นมีที่อ่านและที่ลงมือ ทุกตัวอย่างคอมไพล์รันได้จริงบนมือถือ (English version: [LEARN_EN.md](LEARN_EN.md))

**หลักการ:** ทีละแนวคิด · อธิบายด้วยภาษาตัวเองได้ · ลองโยงกับโค้ดจริง · ไม่ต้องอ่านทั้งเล่มก่อนลงมือ · อย่ากระโดดไป SIMD หรือคูณเมทริกซ์ก่อนเข้าใจหน่วยความจำ

| 2 | เขียนโปรแกรม: ตัวแปร เงื่อนไข ลูป ฟังก์ชัน | [BASICS บท 1-9](BASICS.th.md), [หนังสือ: เขียนโปรแกรม](book/programs.md), [TUTORIAL บท 1-23](TUTORIAL.th.md) | โจทย์ท้ายบททุกข้อ |
| 3 | โครงสร้างข้อมูลและอัลกอริทึม | [หนังสือ: โครงสร้างข้อมูล](book/ds.md), TUTORIAL บท 141-143, 153-162 | เขียน stack, queue, heap, hash เอง |

| 6 | ภาษา J2K ให้ลึก | [หนังสือ: jcmp](book/jcmp.md), [LANGUAGE](LANGUAGE.md), [COOKBOOK](COOKBOOK.md) | ทำโปรเจกต์เล็ก 1 อัน |

## แผน 7 วันแรก (วันละ 30-45 นาที)

แต่ละวัน: อ่าน 1 หัวข้อสั้น · เขียนสรุป 5 บรรทัดด้วยภาษาตัวเอง · ทำโจทย์คิด 2 ข้อ หรือโค้ดสั้น 1 อัน

| วัน | เรียน | ที่อ่าน |
|---|---|---|
| 1 | คอมพิวเตอร์ทำอะไรได้ | หนังสือ: คอมพิวเตอร์พื้นฐาน บทแรก |
| 2 | บิตและไบต์ | หนังสือ: เลขฐานสองและบิต, ตัวอักษรและ Unicode |
| 3 | ตัวแปร อาเรย์ และที่อยู่ในหน่วยความจำ | BASICS บท 2, 8 และหนังสือ: เครื่องและความเร็ว บทที่ว่าด้วยที่อยู่ |
| 4 | ทำไมแรมช้า และ cache คืออะไร | หนังสือ: เครื่องและความเร็ว บท cache |
| 5 | ลูปเดินต่อเนื่อง กับกระโดดมั่ว | TUTORIAL บท 109, 163 |
| 6 | ijk กับคูณเมทริกซ์ | TUTORIAL บท 97-101 |
| 7 | ทบทวนทั้งสัปดาห์ เขียน 1 หน้า | สรุปของคุณเอง |

**ของที่ต้องมีในหัว:** เครื่องทำของง่ายๆ ซ้ำๆ · ข้อมูลเป็น 0/1 · CPU เร็ว แรมช้า · ข้อมูลเรียงดี = เร็วขึ้น · GEMM คือคูณเมทริกซ์ · เร่ง = ลดการรอข้อมูล + คำนวณหลายค่าพร้อมกัน

**อย่าทำ:** กระโดดไป SIMD/GEMM ก่อนเข้าใจ memory · อ่านหลายหัวข้อพร้อมกันโดยไม่สรุป · ท่องคำศัพท์โดยไม่อธิบายเป็นภาษาตัวเอง

## ถ้าอยากเล่นเกมเรียน
โปรแกรม `learnj` (`jc install learnj`) ใช้เนื้อหาชุดเดียวกัน เป็นแบบฝึกถามตอบและสอบในเทอร์มินัล (ไม่จำเป็นต้องใช้ ถ้าชอบอ่านหนังสือมากกว่า)
